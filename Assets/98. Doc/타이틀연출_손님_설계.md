# 타이틀 연출 · 손님 설계 (2026-11-17)

> 입력 에셋: `99. External Assets/Anime Tokyo` · `99. External Assets/Toon City People` · `Kevin Iglesias/Human Animations` (Human Basic Motions 2.4)
> 근거: FBX를 직접 파싱해 센 삼각형 수, `.mat`/`.meta`/`.prefab` 설정. **아직 Quest 실기기에서 재 본 것은 없음** — 수치는 추정이며 구현 후 OVR Metrics로 확인 필요.

### 1-2. Toon City People — "변형 프리팹을 그대로 사용"

- 변형 프리팹 115개(여 12×5, 남 11×5). 각 SkinnedMeshRenderer 10개, 아틀라스 1024 1장, 머티리얼 1개, 약 3천~5천 삼각형.
- **원본(Source) 프리팹은 숨은 부위 200개를 포함** → 런타임 스폰 금지. 새 조합이 필요하면 에디터 빌더로 구워서 사용.
- 툰 아웃라인 셰이더(Amplify 생성, URP) 2패스 → 1명당 드로우콜 약 20. `CampaignConfig` 기준 하루 손님 3~6명, 동시 2~3명이라 **메시 합치기 없이도 예산 안**. 합치기는 여유 시 최적화로 미룸.
- Unity 6 / URP 17에서 Amplify 셰이더가 Quest 빌드에서 정상인지 **실기기 확인 필요** (실패 시 Shader Graph 툰으로 교체).
- 리그 Humanoid(`animationType: 3`) → Kevin Iglesias 애니메이션과 리타깃 호환.

### 1-3. Kevin Iglesias Human Basic Motions — "사용함 (Mixamo 불필요)"

- Humanoid, 남(HumanM)·여(HumanF) 세트 분리, 이동은 제자리 버전과 루트모션 `[RM]` 버전 둘 다 있음. 걷기 루프 설정 완료(`loopTime: 1`).
- 아바타 마스크 9종(상체·머리·팔·손), 마스크 포즈(`HandsClosed01`, `ObjectGripHands01`) 포함.
- 전체 223MB지만 **빌드에는 참조한 클립만 포함**. `HumanBasicMotions_BlenderFiles.zip`(8MB)은 빌드에 안 들어감.
- `SpineProxy.cs`는 상·하체 마스크를 섞을 때 Kevin 리그용 보정 스크립트 → TCP 캐릭터에서는 **상체 레이어에서 허리가 틀어질 때만** 검토.
- 정리 권장: 폴더 규칙에 맞춰 Unity 에디터 안에서 `99. External Assets/`로 이동 (GUID 유지되므로 참조 안 깨짐).

## 2. 타이틀 연출 (A안)

### 2-1. 흐름

```
앱 시작 → TitlePhase
  ① 어두운 공간 + 큰 곡면 스크린(시야 60~70%)에 비행 영상 재생 (10~15초, 트리거로 건너뛰기)
  ② 영상 마지막 프레임 = 카드 간판 가게 정면
  ③ 0.4초 전환: 스크린이 투명해지며 뒤에 미리 놓인 실시간 3D 가게 앞 거리가 드러남 (매치 컷)
  ④ 간판 로고 점등 → Ray 메뉴(시작 / 이어하기 / 크레딧, `VrUiStyle` 규격) 등장
```

- 플레이어 시점(XR Origin)은 **움직이지 않음** → 멀미 없음.
- 플레이어 키가 달라 매치 컷이 픽셀 단위로 맞지는 않음 → 녹화 카메라 눈높이 1.6m, 전환은 디졸브로 차이를 가림.
- 영상은 **앱을 처음 켰을 때만** 재생, "처음부터"로 돌아온 타이틀은 바로 ④부터.

### 2-2. 구성

| 구분 | 위치 | 내용 |
|---|---|---|
| 녹화 씬 (빌드 제외) | `00. Scenes/_Recording/TitleFlyover_Rec.unity` | Anime Tokyo `DEMO City Crossing` 복사 + 우리 가게 세트 + 간판. Timeline + Cinemachine 돌리 경로. PC 품질 그대로 |
| 영상 | `04. Art/Video/TitleFlyover.mp4` | Unity Recorder, 1920×1080 · 30fps · H.264 · 약 8Mbps → 약 15MB |
| 타이틀 거리 (빌드 포함) | `00. Scenes/TitleStreet.unity` | 가게 건물 + 양옆 건물 2~3 + 간판·전신주·소품. TitlePhase 진입 시 additive 로드, 게임 시작 시 언로드 |

## 3. 손님

### 3-1. 데이터 (수치는 SO에만)

```
CustomerRoster (SO)
 ├ entries: { prefab, gender: M|F, group: Local|Foreign }
 └ groupWeights: Local 85 / Foreign 15
CustomerSpawner: 그룹 가중치 추첨 → 그룹 안 무작위 (최근 N명 중복 방지) → CustomerAgent에 외형·Animator 부착
```

- 115개 분류는 사람이 눈으로 함 → 에디터 도구로 **썸네일 시트**를 뽑아 한 번에 분류.
- 아시아계로 보이는 조합이 부족하면 `CustomerPrefabBuilder`(CSV → 원본 프리팹 셀렉터 적용 → 숨은 부위 삭제 → 프리팹 저장)로 추가.

### 3-2. Animator

- 기본 컨트롤러 `Customer.controller` 1개 + `AnimatorOverrideController` 2개(남/여 클립 교체).
- 레이어: Base(Idle ↔ Walk, 파라미터 `Speed` = NavMeshAgent 속도) / 상체(`Human Body Upper Mask`, 트리거로 제스처) / 머리(`Human Head Mask`).
- 걷기 클립 속도에 맞춰 NavMeshAgent 속도를 정해 발 미끄러짐을 줄임.

### 3-3. CustomerAgent 상태와 연결 (설계서 7-4)

> 구현 (2026-11-17): 설계서의 NavMesh 대신 **웨이포인트 직선 이동**으로 시작. 매장이 카운터 하나뿐인 열린 공간이라 경로 탐색이 필요 없고, NavMesh 베이크 · 에셋 관리가 빠짐. 매장 모델이 들어와 장애물이 생기면 NavMeshAgent로 바꿈.
> 코드: `Runtime/Customers/CustomerDirector` (일정 · 줄 · 결제) · `CustomerAgent` (걷기 · 제스처) · `Logic/CustomerRules` (외형 뽑기 · 등장 일정, 테스트 있음) · 에디터 `Editor/Customers/*` · `Editor/Scenes/CustomerFloorBuilder`

| 상태 | 애니메이션 |
|---|---|
| Enter | Walk → 입구에서 HandWave |
| Browse | 진열대 앞 Idle + Question, 낮은 칸이면 Loot |
| 구매 판정 (`SalesRules`) | 산다 = HeadNod · 레어 이상 = Cheer / 안 산다 = HeadShake |
| Queue | Idle01 ↔ Idle02 · 맨 앞에 도착하면 Talk + **물건을 카운터에 올림** (진열 카드 = 그 카드, 아니면 가게 재고 카드팩. `SalesRules.PickPurchase`) |
| 계산 (플레이 피드백) | 플레이어가 **바코드 스캐너**를 잡고 트리거로 물건을 찍음(삑 + 진동 + 이름·가격 표시) → 결제 버튼 → `SalesRules.CompleteSale`로 장부 기록. 찍기 전 결제 버튼은 안내만, 기다리다 떠나면 판매 없음 |
| WaitPay | Talk, 인내 시간 초과 시 Angry 후 Leave |
| Leave | Walk (나가며 HandWave) |

## 4. 구현 순서

1. **손님** (핵심 루프): Roster SO · Spawner · Animator(Kevin) · CustomerAgent 연결 · 썸네일 분류 도구
2. **타이틀 최소판**: TitleStreet 씬 · 간판 로고 · 메뉴 (이것만으로 타이틀 완성)
3. **비행 영상**: 녹화 씬 · Cinemachine 경로 · 녹화 · VideoPlayer 스크린 · 매치 컷
4. 여유 시: 손님 메시 합치기, 직접 조합한 아시아계 프리팹, Kevin 폴더 이동

- 메뉴 항목 (시작 / 이어하기 / 크레딧 외에 설정이 필요한가)
- 영상 길이 (10초 vs 15초)
- Local / Foreign 비율 (초안 85 / 15)
- 타이틀 거리에 손님 2~3명을 Idle로 세워 둘지 (드로우콜 약 +40~60)
