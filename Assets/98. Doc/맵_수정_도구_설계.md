# 맵 수정 도구 설계 (2026-11-20)

메뉴: **Tools > CardShop > Map Edit**. 게임을 실행하지 않은 채로 실행 중에만 보이는 것을 씬에 꺼내고, 씬 뷰에서 평소처럼 옮긴 뒤 저장합니다.

## 0. 처음 요청과 보완

- 처음 요청: 도구를 켜면 게임 시작 후에 나오는 오브젝트가 모두 나타나고, Transform을 직접 조정해 저장합니다.
- 보완한 점: 아래 1~7장. 오브젝트 종류마다 저장할 곳이 다르다는 점이 핵심입니다.

| 종류 | 예 | 저장되는 곳 |
|---|---|---|
| ① 씬에 있지만 꺼져 있는 것 | 판 `Content`, 쓰레기, `HomeLight`, 일시정지 메뉴 | 그 오브젝트의 Transform |
| ② 실행 중에 생기지만 씬 Transform을 따라가는 것 | 카드 보관함 · 사장님 메모 자리표, 선물팩 · 무료팩 자리, 계산대 물건 자리 | 기준 Transform(자리표) |
| ③ 실행 중에 생기고 코드 숫자로 자리가 정해지던 것 | 조작 안내 판, 알바 수칙 포스터, 가게 시계, 사직서 스위치, 택배 상자 줄 | 새 자리표 `PlacementAnchor` (2장) |

손님 · 도둑 · 카드 · 말풍선 · 차 · 행인처럼 움직이는 것은 배치 대상이 아닙니다.

## 1. Play 중이 아니라 편집 모드에서 수정

- **문제:** Play 중에 옮긴 값은 Play를 끄면 사라집니다. 실행 중에 코드가 위치를 계속 덮어쓰는 물건도 있습니다.
- **보완:** `MapEditMode`가 편집 모드에서 꺼진 것을 켜고 미리보기 모형을 띄웁니다. Play 중에는 창이 잠깁니다.

## 2. 실행 중에 생기는 물건 = 자리표

- **문제:** ③은 씬에 없는 물건이라, 옮겨도 저장할 곳이 없습니다.
- **보완:** 범용 자리표 `PlacementAnchor`(키 이름 포함)를 두고, 물건 코드는 `PlacementAnchor.Find(키, 기본 자리)`로 자리를 읽습니다.
  - 자리표가 없으면 예전 기본 자리를 쓰므로 지금 게임은 그대로입니다.
  - 도구를 켜면 자리표마다 실제 크기의 반투명 모형을 띄웁니다(`HideFlags.DontSave`라 저장되지 않음).
  - `[SelectionBase]`를 붙여서, 모형을 클릭해도 자리표가 선택됩니다.

## 3. 코드 숫자로 자리가 정해지던 5곳

| 자리표 키 | 물건 | 기본 자리 |
|---|---|---|
| `Sign/Controls` | 조작 안내 판 (`TutorialSigns`) | 타이틀 판 왼쪽 1.05m |
| `Sign/Rules` | 알바 수칙 포스터 (`TutorialSigns`) | 계산대 뒤 벽 |
| `Sign/ShopClock` | 가게 디지털 시계 (`ShopTimerBoard`) | 정면 벽 창문 위 |
| `Home/ResignSwitch` | 사직서 스위치 (`ResignSwitch`) | 잠자기 스위치 옆 0.3m |
| `Home/DeliveryBoxes` | 택배 상자 줄 (`RoomUpgradeView`) | 첫 상자 자리. 오른쪽으로 4개씩, 넘치면 뒤로 0.5m |

- 창의 **만들기** 버튼을 누르면 기본 자리에 자리표가 생깁니다(씬 맨 위 `PlacementAnchors` 아래). 그래서 만든 직후의 게임 모습은 그대로입니다.
- 새 물건을 더하려면 물건 코드가 `PlacementAnchor.Find`를 쓰게 고치고, `MapAnchorCatalog.All`에 한 줄을 더합니다.
- 바닥 얼룩이나 쓰레기처럼 매번 무작위로 생기는 자리는 대상이 아닙니다.

## 4. 켠 것은 저장 전에 원래대로

- **문제:** 꺼진 것을 켠 채로 저장하면 게임 첫 상태가 망가집니다.
- **보완:** 도구가 켠 목록을 기억해 두었다가 다음 순간에 다시 끕니다.
  - 끝내기를 누를 때
  - Play를 시작할 때 (Play를 끝내면 모드를 다시 켬)
  - 씬을 저장하기 직전 (저장한 뒤 다시 켬)
  - 씬을 닫을 때
  - 스크립트를 다시 불러올 때 (불러온 뒤 다시 켬)
- 프리팹 안 오브젝트는 끌 때 "켜짐" 오버라이드도 지워서, 프리팹 변경이 남지 않게 합니다.

## 5. Build Shop Scene 뒤에도 유지

- **빌더가 만드는 물건:** 이름표(`PlacementKey`)가 있으면 지금처럼 `PlacementMemory`가 옮긴 자리를 지킵니다.
- **이름표가 없는 물건:** 창에서 **이름표 붙이기**를 누르면 키가 계층 경로로 정해집니다(`PlacementKey.MarkByHand`, `addedByHand`). 빌드 전에 늘 기억해 두었다가, 새 씬에서 같은 경로를 찾아 되살립니다(`HierarchyPath`).
- **자리표:** 빌더가 만들지 않으므로, `AnchorMemory`가 새 씬을 만들기 전에 적어 두었다가 다시 만듭니다. `PlacementAnchor`, `CardCaseAnchor`, `TutorialMemoAnchor`가 대상입니다.

## 6. 손님 동선 보기

- **문제:** 가구를 옮겨도 손님 지점은 따라오지 않아서, 손님이 가구와 겹칠 수 있습니다.
- **보완:** `RouteGizmoDrawer`가 `CustomerDirector`에 연결된 지점을 씬 뷰에 그립니다.
  - 원: 손님 한 명 자리(지름 0.5m)
  - 짧은 선: 손님이 바라보는 쪽
  - 점선: 지나는 차례 (주황 = 들어오기, 노랑 = 계산대 줄, 초록 = 구경, 빨강 = 나가기, 보라 = 도둑)
- 지점은 씬 Transform이라 직접 옮길 수 있고, 이름표가 있어 빌드 뒤에도 유지됩니다.

## 7. 겹침 · 되돌리기

- 숨은 것은 씬 맨 위 묶음별로 보이기를 켜고 끌 수 있습니다.
- 옮기기는 Ctrl+Z로 되돌릴 수 있습니다.
- 되돌리는 버튼은 두 가지입니다.
  - **기본 자리로:** 이름표가 기록한 빌더 기본 자리로 돌아갑니다.
  - **코드 기본 자리로:** 자리표를 코드에 적힌 기본 자리로 돌려놓습니다.
