# 카드 도둑 설계

> 2026-11-18 · 관련: [DEC-015](../../DevLog/decisions/DEC-015-손님-물결로-틈을-만들고-사건-조율은-하지-않음.md)(사건 조율 안 함, 보완 4-3), [`기기테스트_피드백_설계.md`](기기테스트_피드백_설계.md) 4장, HANDOFF "카드 도둑"
> 상태: 설계 확정 · 코드 작성(Unity 컴파일 · 실기기 확인 전)

## 1. 한 줄 요약

3일차부터 하루 한 번, **복면 쓴 손님이 계산대 위 "오늘 무료 팩"을 들고 도망**갑니다. 카운터 옆 **빗자루로 한 대** 치면 팩을 떨어뜨리고 달아나고, 놓쳐서 인도 끝(문에서 10m)에 닿으면 **그날 퇴근 후 무료 팩이 없습니다.**

## 2. 확정한 것 (2026-11-18 사용자 선택, 모두 추천안)

| 항목 | 결정 | 이유 · 근거 |
|---|---|---|
| 훔치는 것 · 벌칙 | **오늘 무료 팩**. 놓치면 그날 무료 팩 0개 | 게임에 "그날 깔 팩 재고"가 따로 없음. 무료 팩(하루 1개)이 "내가 깔 팩"에 가장 가깝고, 알바비는 건드리지 않음(DEC-012: 실패가 너무 아프지 않게) |
| 빈도 | **3일차부터 하루 1번** | 1~2일차는 계산 · 청소를 익히는 날. 3일차부터 영업 135초 이상이라 틈이 있음 |
| 잡는 법 | **빗자루로 한 대** | 청소와 같은 도구. 추격이 짧게 끝남(DEC-015 보완: 10~15초) |
| 구분 | **손님 모델 + 복면 소품** | 따로 만든 도둑 모델이 없음. 들어올 때부터 보여서 "저 사람 수상한데?"를 미리 알 수 있음 |
| 줄 손님 인내 시간 | **멈추지 않음** | DEC-015(B안 안 씀). 대신 잡으면 줄 손님 인내 시간 +10초 회복(영웅 보너스) |

## 3. 흐름

```
등장(복면, 걷기) → 계산대 앞(손님 쪽 왼쪽)에 섬 → 1.5초 머뭇 → 무료 팩을 집음("이건 공짜죠? ㅎㅎ" + 알림)
→ 1초 약 올림 → 달아남(빠르게): 진열대 옆 통로 → 문 → 인도 → 왼쪽/오른쪽 10m
   ├ 빗자루에 맞음 → "으악!" 팩을 그 자리 바닥에 떨어뜨리고 밖으로 도망 → 줄 손님 박수 + 인내 +10초
   │                   → 떨어진 팩을 집으면 계산대 받침으로 돌아감 ("되찾았다!")
   │                   → 안 집고 영업이 끝나도 되찾은 것으로 침 (잡은 게 핵심)
   └ 인도 끝 도착     → "도둑을 놓쳤어요…" → 장부에 도난 기록 → 퇴근 후 무료 팩 0개
```

- **맞기 전에도** 맞으면 잡힘: 팩을 집기 전(머뭇거릴 때)에 쳐도 됨 → 복면을 보고 미리 막는 재미.
- 등장 시각: 영업 시간의 25~60% 사이 무작위. 손님 물결과 겹칠 수 있음(일부러: 누구를 잃을지 고르는 판단).
- 영업 시간이 끝나도 도둑이 남아 있으면 끝날 때까지 기다린 뒤 정산(손님과 같음).
- 일시정지 중에는 도둑 · 타이머도 멈춤.

## 4. 수치 (모두 `CampaignConfig.thief`에서 조절)

| 값 | 기본 | 근거 |
|---|---|---|
| 첫 등장 일차 · 하루 횟수 | 3 · 1 | 2장 |
| 등장 시각 (영업 시간 비율) | 0.25 ~ 0.6 | 처음 물결 뒤, 영업이 끝나기 한참 전 |
| 도둑 달리는 속도 | 1.8 m/s | 플레이어 이동 2.5 m/s(XR Origin 기본)보다 느리게 → 멀미 없이 따라잡힘 |
| 머뭇 · 약 올림 | 1.5초 · 1초 | 알아챌 시간 |
| 도망 거리 | 문에서 인도 따라 10m | 경로 약 17m ÷ 1.8 ≈ 10초 → DEC-015 "10~15초 안에 끝" |
| 빗자루 맞음 판정 | 빗자루 머리 속도 1.0 m/s 이상 + 도둑 몸(반지름 0.35m, 키 높이) 안 | 톡 댄 것은 안 침, 휘둘러야 함 |
| 영웅 보너스 | 줄 손님 인내 +10초 | DEC-015 보완 |

## 5. 구조

| 파일 | 맡는 일 |
|---|---|
| `Logic/ThiefRules.cs` (순수 C#, 테스트) | 등장 시각 · 오늘 나오는지 · 맞음 판정 · 퇴근 후 무료 팩 수 · 다가가는 길 / 도망 길 |
| `Customers/ThiefDirector.cs` | 도둑 하나의 흐름(등장 → 훔침 → 도망 → 잡힘/놓침), 팩 · 빗자루 · 복면 다루기. `IThiefFloor`로 영업 마감이 기다림 |
| `Customers/Broom.cs` | 빗자루 머리 위치 · 속도, 쥐고 있는지 |
| `CustomerDirector` | 손님 외형으로 도둑 몸 만들기(`SpawnExtra`), 통로(`Routes`), 영웅 보너스(`CheerThiefCaught`) |
| `GameSession.DayLedger` | `freePackStolen`, `thievesCaught` |
| `AfterHoursPhase` | 무료 팩 수 = `ThiefRules.FreePacksToday` |
| `Editor/Scenes/ThiefBuilder.cs` | 빗자루(카운터 오른쪽 뒤), 오늘 무료 팩 받침(계산대 손님 쪽 왼쪽), 복면 원본(꺼 둠), 도둑 서는 자리, 도망 지점 2개 |

위치(`ShopLayout`): 무료 팩 = 계산대 윗면 손님 쪽 왼쪽 (−0.9, 0.9, 0.9) — 팩 테이블 위는 팩 선반 12칸이 차지해서 계산대로 옮김. 도둑 서는 자리 = 그 앞 (−0.9, 0, 1.4), 빗자루 = (1.35, 0, 0.12) 카운터 오른쪽 뒤(문 쪽으로 나가며 집기 좋게), 도망 지점 = 문 x ± 10, 인도 z 6.4.

## 6. 눈으로 확인할 것 (렌더 · 실기기 전)

- 복면 위치 · 크기(머리 뼈 기준, 손님 모델마다 다를 수 있음), 앞이 맞는지
- 도둑이 계산대 앞에서 지나가는 손님 · 진열대와 겹치지 않는지
- 달릴 때 걷기 동작이 어색하지 않은지 (애니메이터는 속도만 받음)
- 빗자루 크기 · 쥐는 느낌, 1.0 m/s 판정이 너무 쉽거나 어려운지
- 오늘 무료 팩 받침이 계산대의 다른 물건(상자 열기 · 퇴근 버튼, 결제 버튼)과 겹치지 않는지. 빗자루가 쓰레기통 · 카운터와 겹치지 않는지
