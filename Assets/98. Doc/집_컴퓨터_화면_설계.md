## 2. 화면 모양 — "모니터 한 대, 페이지 두 장"
```
┌──────────── 모니터 1.3 × 0.9m ────────────┐
│ [ 커뮤니티 ]  [ 슬라임마켓 ]        ● ○    │ ← 탭(누르면 바로 이동) · 쪽 점
│ ◀                                      ▶ │ ← 양옆 화살표 (레이 클릭)
│        (지금 페이지 내용, 좌우로 밀림)        │
│                                           │
└───────────────────────────────────────────┘
```
- **넘기는 방법 (추천 조합)**: ① 탭 누르기 ② 양옆 화살표 ③ **레이로 화면을 잡고(트리거 누른 채) 좌우로 끌기** — 화면 폭의 15% 이상 끌거나 빠르게 휙 밀면 다음 쪽, 아니면 제자리로 튕겨 돌아옴. `[결정 필요] Q1`
- 넘길 때 페이지가 옆으로 0.25초 미끄러지고, "딸깍" 소리(`UiClick` 재사용) + 약한 진동.
- 처음 집에 오면 **커뮤니티 쪽**부터 (내일 인기 속성이 판매 판단에 먼저 필요). `[결정 필요] Q5`
- 택배가 와 있거나(도착) 살 돈이 충분한 새 물건이 있으면 마켓 탭에 작은 점(●) 표시 — "볼 이유"를 만들어 줌.
- 오른쪽 벽의 마켓 화면은 **없앰**. `[결정 필요] Q3`

## 3. F8 슬라임마켓 다듬기 — "쇼핑몰처럼"
지금: 이름 · 단계 · 효과 글자 한 줄 + [가격 사기] 버튼 × 8줄.

```
│ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐                 │
│ │[그림] │ │[그림] │ │[그림] │ │[그림] │   상품 카드:     │
│ │진열장 │ │바인더 │ │컴퓨터 │ │침대   │   그림 · 이름    │
│ │●●○   │ │●○○   │ │●○○   │ │●○○   │   단계 점       │
│ │6칸으로│ │판매칸+2│ │모레예보│ │인내+10%│  다음 효과 한 줄 │

```
- **상품 그림**: 가구 모델을 에디터에서 한 번 찍어 PNG로 저장(`UpgradeIconBaker`, 에디터 전용) → `UpgradeCatalog` 단계마다 `icon` 칸. 실행 중 렌더링 없음(Quest 성능). `[결정 필요] Q6`
- **상태 표시**: 주문함 = 카드 위에 파란 "배송 중" 띠, 도착 = "택배 도착!" 띠 + 반짝, 최고 단계 = 초록 "완료" 도장, 돈 부족 = 가격 띠가 회색.
- **사기**: 상품 카드를 누르면 카드가 살짝 커지며 아래에 [$40 사기] 버튼이 나옴 → 누르면 삼. 지금의 "4초 안에 두 번 누르기"와 같은 안전장치지만, 무엇을 사는지 눈에 보임.
- **색 · 글꼴**: `UiTheme`(DEC-027 카드샵 굿즈 테마) 색을 그대로, 제목 옆에 슬라임 마스코트 그림 1장(카드 아트 중 하나 재사용).
- **커뮤니티 쪽도 같이**: 지금 글자 3덩이 → "게시판" 모양(오늘 / 내일 인기 속성 = 속성 아이콘 큰 배지, TOP3 = 카드 그림 작은 썸네일 + 가격, 분위기 글 = 댓글 말풍선 2~3개). 카드 그림은 `CardData` 아트를 그대로 씀.

> 참고 UI 샘플을 찾는 일은 사용자가 고르는 편이 좋습니다(취향). 위 그림은 "게임 속 쇼핑앱"의 흔한 모양(격자 상품 카드 + 가격 띠 + 상태 리본)을 기준으로 했습니다. `[결정 필요] Q4`

## 6. 위험 · 확인할 것
- **레이 끌기 감도**: XRI UI 입력 모듈의 끌기 시작 거리(`trackedDeviceDragThresholdMultiplier`)가 2.6m 거리에서 너무 예민 / 둔할 수 있음 → Play로 맞춤.
- **끌다가 버튼 눌림**: uGUI 규칙상 끌기가 시작되면 클릭이 취소되지만, XRI 모듈에서도 그런지 Play로 확인.
- **글자 크기**: 모니터가 2.6m 떨어져 있어 상품 카드 글자가 작게 보일 수 있음 → 카드 격자를 4 × 2로 크게, 작은 글자는 22pt(22mm) 아래로 내리지 않음. 책상 앞까지 다가와야 읽힌다면 Q1 "손 밀기"도 같이 고려.
- **J6와 자리**: 진열장을 모니터 위로 옮기면 모니터 위 공간이 줄어듦 → 화면은 지금 모니터 크기 안에서만 그림.
