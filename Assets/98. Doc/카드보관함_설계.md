# 카드 보관함 설계 (J5 손으로 집어 꽂는 카드 전용 진열장, J6 자리 포함) — 초안 11-20

> 출처: [빌드피드백_11-20_FIX제안](../../DevLog/빌드피드백_11-20_FIX제안.md) J5 · J6 · 캡처 8, [게임피드백_체크목록](../../DevLog/게임피드백_체크목록.md) 5-5 · 5-6 · 7-1, [집_업그레이드_설계](집_업그레이드_설계.md) 2장 E1 · 7장
> 상태: **11-20 밤 일부 구현 (추천안)**: `CardCase`(모니터 위 벽 나무 틀 · 홈 10칸 · 잠긴 칸 덮개 · 3단계 조명, J6) · `CardCaseAnchor` + 메뉴 · 꽂힌 카드를 손으로 다른 칸으로 옮기기 / 바인더 위에 놓으면 내리기 / 그 밖은 원래 칸(Q7) · `ShowcaseRules.MoveTo`(+테스트). **꺼내기는 Q1의 다른 안 ②**: [진열장에 세우기] → 카드가 바인더 위에 떠오르고 손으로 집어 칸에 꽂음(바인더 칸 그립 꺼내기 J5-c는 Play 감도 조정이 필요해 안 함). 칸 판정은 소켓 대신 거리. 책장 앞 진열대(ShowcaseShelf)는 지움. 표지 소켓 정리(Q6) · 튜토리얼 한 줄 · 칸 번호 배열은 안 함. Play 확인 전.
> ⚠ **DEC-023(바인더 · 판매는 레이 클릭, 손으로 꽂기 없음)을 진열장에 한해 바꾸는 설계**입니다. 확정하면 새 결정 기록(DEC-034 후보)을 남깁니다.

## 0. 왜 필요한가 (피드백)
- 5-5 "책장 말고 카드 전용 보관함에 직접 집어서 놓고 싶다" · 캡처 8: 피규어 선반 앞에 카드가 **떠 있는** 것처럼 보임
- 5-6 "바인더 UI에서 직접 카드를 집고 보관하는 경험이 없어서 모으는 경험을 잘 못 느낌"
- 7-1 (J6) "진열장 위치를 컴퓨터 모니터 위로"
- 지금은 바인더에서 고르고 → 오른쪽 패널 [진열장에 세우기] 버튼 → 책장 앞에 카드가 나타남. **손으로 하는 일이 없음.**

## 1. 지금 구조에서 확인한 사실 (코드)
| 항목 | 지금 | 이 설계에 주는 영향 |
|---|---|---|
| 진열 규칙 (`ShowcaseRules`, 순수) | 진열하면 `Collection`에서 빠져 `GameSession.Showcase`(List, 순서만)로. 칸 수는 진열장 단계 3 · 6 · 10 | 규칙은 그대로 씀. 다만 **"몇 번 칸에 꽂았나"를 기억하지 않음** → 손으로 꽂은 칸에 그대로 있으려면 칸 번호가 필요 |
| 진열대 (`ShowcaseShelf`, 173줄) | 책장(`Bookshelf`) 경계 상자 앞면에 나무 받침 2줄(5칸씩)을 코드로 만들고, 카드 프리팹 + `CardRevealView`를 세움. 잡으면 꺼내 보기, 놓으면 제자리로 날아감 | 책장 **앞에** 받침을 붙여서 떠 보임(캡처 8). 자리를 코드가 계산 → 씬에서 옮길 수 없음 |
| 진열 패널 (`ShowcasePanel`, 167줄) | 바인더 오른쪽, 레이 클릭으로 세우기 · 내리기 | 손으로 꽂게 되면 보조 수단으로 남기거나 없앰 `[결정 필요] Q5` |
| 바인더 (`BinderView` 295줄 · `BinderSlotView` 139줄) | 한 쪽 분량의 칸만 있는 월드 캔버스, 레이 클릭으로 고르기. **집에 실물 카드가 없음**(카드는 데이터) | 손으로 꽂으려면 **바인더에서 실물 카드를 꺼내는 길**이 새로 필요 |
| 소켓 선례 | 가게 선반 `ShelfSlotSocket`(XRSocketInteractor, 팩만 받음 · 앞뒤 자세), 바인더 표지 `BinderCoverSocket`(카드만 받음, DEC-023 뒤 쓰지 않는 보조 기능) | 같은 방식으로 "카드만 받는 칸 소켓"을 만들면 됨 |
| 카드 오브젝트 | 카드 프리팹 + `CardRevealView`(잡기 · `FlyTo` · `GrabEnded` 이벤트), `UpgradeCatalog.showcaseCardPrefab` | 꺼낸 카드 · 진열 카드 모두 이것을 재사용 |
| 업그레이드 (`UpgradeRules`) | 진열장 단계 → 칸 수 · 3단계 조명 | 그대로. 단계마다 보관함 모양을 바꿀 수 있음(Q3) |
| 점수 (`ScoreRules`) | 진열 카드도 카드 가치에 들어감(이중 계산 없음, DEC-031 Q4) | 바뀌지 않음 |
| 진열 목록을 쓰는 곳 | `ShowcaseShelf` · `ShowcasePanel` · `ScoreRules` · `FinalShowcaseStrip` | 칸 번호를 넣어도 고칠 곳이 적음 |

## 2. 손으로 하는 흐름 — "바인더에서 꺼내 → 보관함에 꽂기"
```
바인더 칸을 가리키고 그립(쥐기) ─► 그 카드 실물이 손에 쥐어짐 (보유 1장 → "꺼낸 중")
        │
        ├─ 보관함 빈 칸에 가져가면 칸이 빛남 → 놓으면 "착" 꽂힘 (진동 · 소리) ─► 진열 확정
        ├─ 바인더 위에 놓으면 / 아무 데나 놓으면 ─► 바인더로 날아가 돌아감 (진열 안 됨)
        └─ 집을 나가면(침대) 손에 든 카드는 바인더로 자동 정리
보관함의 카드를 쥐면 ─► 빼서 볼 수 있음
        ├─ 다른 빈 칸에 꽂으면 자리 옮김
        └─ 바인더에 가져가 놓으면 진열 내리기 (보유로 돌아감) / 아무 데나 놓으면 원래 칸으로
```
- **꺼내기 = 그립, 고르기 = 트리거**: 지금 바인더의 레이 클릭(트리거, 판매 · 진열 패널용)은 그대로 두고, **그립**으로 칸을 쥐면 카드가 나옴. 버튼이 달라 서로 안 섞임. `[결정 필요] Q1`
- 꺼낸 카드는 **레이 끝에서 손으로 날아와 쥐어짐**(XRI 레이 잡기의 "당겨 오기"와 같은 느낌). 책상 앞에 서서 바로 꽂을 수 있게 보관함은 책상 가까이(Q2).
- 진열 칸이 꽉 찼으면 꽂히지 않고 칸이 빨갛게 한 번 깜빡 + "진열장이 꽉 찼어요" 말풍선(혼잣말 자막).
- 보관함 칸 수가 업그레이드로 늘면 새 칸이 빈 홈으로 나타남.

## 3. 보관함 모양 · 자리
- **모양 (추천)**: 벽걸이 **카드 액자형 진열장** — 나무 틀 안에 카드 홈(살짝 뒤로 기운 아크릴 칸)이 줄지어 있음. 카드는 홈에 꽂혀 **떠 보이지 않음**. 3단계는 틀 위 조명이 켜짐(지금 규칙).
  - 단계별: Lv1 3칸 한 줄 · Lv2 6칸 두 줄 · Lv3 10칸 두 줄 + 조명 — 틀 하나에 칸 20개 자리를 두고 열린 칸만 보이게 하거나, 단계마다 틀 모델을 바꿈 `[결정 필요] Q3`
- **자리 (추천)**: J6대로 **컴퓨터 모니터 위 벽**. 책상 앞에 서면 손이 닿고, 바인더 · 모니터와 한눈에 들어옴. **씬에 `CardCaseAnchor` 빈 오브젝트를 두고 거기에 붙임 → 사용자가 씬에서 옮길 수 있음.** 없으면 모니터 위 기본 자리. `[결정 필요] Q2`
- **책장은 비움**: 지금 책장 앞 나무 받침 · 카드는 없애고, 책장은 피규어 · 꾸미기(업그레이드 "피규어")용으로 둠. 책 모델을 끌지(빈 책장) 여부는 씬에서 사용자가 정함. `[결정 필요] Q4`
- 모니터 화면([집_컴퓨터_화면_설계](집_컴퓨터_화면_설계.md))과 겹치지 않도록, 보관함 아래 끝은 모니터 위 끝보다 5cm 이상 위.

## 6. 위험 · 확인할 것
- **그립이 레이 클릭과 섞이지 않나**: 바인더 칸 버튼은 트리거(UI 누르기), 꺼내기는 그립(선택) — XRI 레이가 UI 위에 있을 때 그립 선택이 막히지 않는지 Play로 먼저 확인(막히면 칸 앞에 1cm 띄운 콜라이더로).
- **꺼낸 카드 수**: 동시에 여러 장 꺼내 두면 데이터와 화면이 어긋날 수 있음 → 한 손에 한 장, 놓으면 바로 정리(꽂히거나 돌아감)하여 "떠 있는 꺼낸 카드"가 남지 않게.
- **꽂는 감도**: 소켓 반경이 너무 크면 옆 칸에 꽂힘 → 칸 간격(약 9cm)보다 작은 반경 3~4cm.
- **바인더와 보관함 거리**: 바인더(책상 위)와 모니터 위 보관함이 팔 뻗으면 닿는 거리인지 씬에서 확인(자리는 앵커로 사용자가 조정).
