## 1. 상점 버튼 셰이딩 (P1)

### 지금 상태
`CreatePokeButton`이 만드는 버튼 4개(상자 열기 · 퇴근 · 결제 · 불 끄고 자기)는 **7 × 2 × 7cm 큐브 + URP Lit 단색**이고, 글자는 버튼 7cm 위에 떠 있습니다. 둘레에는 흰 판(`ButtonGlowPlate`, 알파 0.6)이 있습니다.

| 문제 | 왜 아쉬운지 |
|---|---|
| 단색 큐브 | 그림자 · 광택이 없어 "누를 수 있는 물건"보다 "색 상자"로 보임 |
| 받침 없음 | 버튼이 계산대 위에 놓인 것인지, 박힌 것인지 구분이 안 됨 → 누르는 깊이가 안 느껴짐 |
| 글자가 공중에 뜸 | 다른 UI(명판 · 꼬리표)와 달리 바탕이 없어 가게 배경에 묻힘 |
| 흰 빛판 | 눈 편한 색 규칙(흰 판 금지)과 어긋남. 모든 버튼이 같은 흰 테 |
| 누름 = 1cm 내려감뿐 | "말랑" 브랜드 · 슬라임 컨셉의 손맛이 없음 |

### 안

| | ⭐ A. 슬라임 젤리 버튼 | B. 아케이드 버튼 |
|---|---|---|
| 모양 | 어두운 진보라 둥근 받침(금 테 한 줄) 위에 **납작한 슬라임 돔 캡** | 크롬 링 받침 + 원통 캡 |
| 셰이딩 | 캡 위쪽에 부드러운 흰 광택 판(알파 0.3) + 아래쪽 진한 색 띠 → 젤리처럼 보임 | 금속 반사 + 캡 위 볼록 광택 |
| 누를 때 | 캡이 **눌리며 납작해졌다가(세로 0.6 · 가로 1.1) 통 튀어 올라옴** (0.25초) | 깊게 들어갔다 나옴 |
| 가리킬 때 | 캡 색이 조금 밝아지고, 받침 금 테가 버튼 색으로 은은히 빛남 | 링 불빛 켜짐 |
| 글자 | 받침 앞쪽에 붙은 **작은 명판**(진보라 판 · 미색 글자, 15° 기울임) | 같음 |
| 잠김 · 쿨다운 | 캡 채도를 낮추고 광택을 끔 (예: 영업 중 상자 열기) | 같음 |
| 장점 | 카드 문양(슬라임 돔 · 금 테)과 같은 말, 손맛 = 생동감 | 오락실 느낌이 확실 |
| 단점 | 런타임 돔 메시 하나 필요 | 카드샵 · 슬라임 컨셉과 멀어짐 |

### 구현 (A안 기준)
- **새 `PokeButtonLook`** (Runtime/Interaction, 예상 150줄): 씬을 고치지 않도록 `ButtonGlowPlate`처럼 **실행할 때 스스로 붙어** 겉모습을 만듭니다.
  - `Cap` 큐브의 MeshRenderer를 끄고 그 자리에 돔 메시(반구를 납작하게, 런타임 생성 · 한 번만 만들어 공유) + 받침(원통 납작) + 광택 판(`UiSprites.Glow`) + 금 테(`UiSprites.Ring`)를 자식으로.
  - 색은 지금 버튼 색(`Cap` 재질 색)을 그대로 읽음 → 버튼마다 색이 달라도 코드 한 곳.
  - 글자: 기존 `Label` TMP를 명판 위로 옮기고 크기 · 색만 바꿈.
- **`PokeButton`** (110줄): 눌림 · 뗌 순간을 알리는 이벤트 `PressChanged(bool)` 한 줄 추가. 말랑 튐은 `PokeButtonLook`이 함. 110 → 약 115줄, 맡은 일 안.
- **`ButtonGlowPlate`**: 흰색 → 버튼 색의 밝은 톤(알파 0.35). 받침이 생기면 판 크기를 받침 기준으로.
- 성능: 버튼 4개 × 렌더러 5개 = 20개, 그림자 끔.

### 월드 UI 버튼(캔버스)도 맞출지 — [결정 필요]
판매 창 · 일시정지 메뉴의 캔버스 버튼은 이미 `UiSkin.StyleButton`이 아래 그림자(`ButtonDepth`)를 줍니다. 위쪽 1/3에 **흰 광택 띠(알파 0.12)** 만 더하면 상점 버튼과 같은 "젤리" 말이 됩니다(`UiSprites`에 띠 스프라이트 하나, `StyleButton`에 3줄). 추천: **같이 함** (작음).

## 2. 고등급 개봉 연출 (P2: 수퍼레어 · 유니크 · 레전더리)

### 지금 상태 (`RevealFx.Announce`)
| 등급 | 지금 | 카드 셰이더 (`CardRarityStyles`) |
|---|---|---|
| 수퍼레어 | 금빛 마름모 14개, 반경 11cm, 0.7초 | 홀로 0.8 |
| 유니크 | **수퍼레어와 같음** (DEC-004 "SR~U 통일") | 홀로 0.9 |
| 레전더리 | 마름모 14개 반경 30cm + 카드 부르르 | 홀로 1.0 · 글로우 1 |

→ 마름모 하나뿐이라 세 등급의 **급 차이가 안 느껴지고**, 폭죽이 카드 평면 위에서만 퍼져 VR에서 납작해 보입니다.

### 설계: 등급마다 "한 층씩 더함" (계단식)
한 등급 올라갈 때마다 요소를 하나씩 더합니다. 그래서 수퍼레어를 본 플레이어가 유니크에서 "어? 하나 더 있다"를 느낍니다.

| 요소 | 수퍼레어 | 유니크 | 레전더리 |
|---|---|---|---|
| 색 (등급 색) | 연보라 (0.92, 0.78, 1) | 금 (1, 0.86, 0.45) | 무지개 (`RainbowDome`과 같은 색 순서) |
| ① 말랑 펀치 — 카드가 1.08배로 통 튀었다 돌아옴 | ✅ 0.25초 | ✅ | ✅ 2번 |
| ② 뒤 후광 — 카드 뒤 둥근 빛(`UiSprites.Glow`)이 커지며 흐려짐 | 작게 (카드 1.4배) | 중간 (1.8배) | 크게 (2.4배) + 천천히 숨쉬기 |
| ③ 슬라임 방울 폭죽 — 마름모 대신 **돔 모양** 방울이 튐 | 8개, 반경 10cm | 12개, 15cm | 18개, 30cm, 두 겹 |
| ④ 별 반짝임 — 카드 테 둘레에 4꼭지 별(`UiSprites.Sparkle`)이 차례로 깜빡 | | ✅ 6개 | ✅ 10개 |
| ⑤ 회전 빛줄기 — 카드 뒤에서 가는 빛줄기가 천천히 돎 | | ✅ 8줄, 알파 0.18 | ✅ 12줄, 알파 0.25 |
| ⑥ 테 빛 훑기 — 카드 셰이더 `_Glow`를 0 → 1 → 0으로 한 번 | | ✅ | (이미 글로우 1, 대신 밝기 맥박) |
| ⑦ 충격파 링 — 카드에서 링(`UiSprites.Ring`)이 앞으로 퍼짐 (입체감) | | | ✅ 2겹 |
| 카드 부르르 · 진동 | (지금 값) | (지금 값) | (지금 값) |
| 총 길이 | 약 0.6초 | 약 1.0초 | 약 1.6초 (넘기면 즉시 꺼짐) |

- **DEC-004 "SR~U 통일"을 바꾸는 것**이라 결정 기록이 필요합니다 → 아래 [결정 필요] P2-1.
- 빛줄기는 DEC-004에서 지운 "팩을 뜯을 때의 하얀 빛줄기 판"과 다릅니다: 카드가 **이미 보인 뒤** 카드 **뒤에** 나오고, 흰색이 아니라 등급 색 · 낮은 알파입니다.
- 입체감: 후광은 카드 2cm 뒤, 방울 일부는 카드 앞 3~6cm로 튀어나오게(앞면 글자는 가리지 않게 카드 가장자리 바깥쪽으로만). 충격파 링은 카드에서 플레이어 쪽으로 8cm 이동하며 퍼짐.
- 성능: 동시에 최대 약 45장 스프라이트, 화면의 작은 부분. 오브젝트는 미리 만들어 재사용(퇴근 후 데우기 `Prewarm`에 포함).

### 구현
- **새 `RevealAura`** (Presentation, MonoBehaviour, 예상 200줄): 후광 · 별 · 빛줄기 · 링을 갖고 `Play(tier, Transform card, Color)` · `Stop()`. 카드를 따라다님(카드가 카운터로 날아가면 같이 꺼짐).
- **`RevealBurst`** (75줄): 모양을 마름모 → 돔(`UiSprites.Dome`)으로, 개수 · 앞뒤 깊이를 인자로. 75 → 약 95줄.
- **새 `RevealPunch`** 또는 `CardRevealView.Punch()` (지금 `Shake`가 있는 자리, 199줄 → 약 215줄, 맡은 일 안: 공개용 카드 상태 · 움직임).
- **`RevealFx.Announce`** (139줄): 등급 → 연출 단계 고르는 부분만 바꿈 (`tier` 통일 줄 제거, Aura · Punch 부르기). 약 150줄.
- **상자 장면(`BoxPackRarityFx`)**: 같은 색 표(수퍼레어 연보라 · 유니크 금 · 레전더리 무지개)만 맞춤. 상자 장면은 팩 10개가 빨리 뜯기므로 ③ 폭죽만 유지.
- 효과음은 지금 칸(`RarityRevealProfile`) 그대로.
