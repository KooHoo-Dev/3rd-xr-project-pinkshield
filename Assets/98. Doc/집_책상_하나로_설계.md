# 집 책상 하나로 · 바인더와 컴퓨터 묶기 설계 — 초안 11-20

> 요청 (11-20): "바인더 UI도 PC UI에 포함시키는 게 어떨까? 컴퓨터 책상이랑 바인더용 책상 두 개로 나눈 것도 혼자 사는 원룸에서는 말이 안 되는 가구 배치. 검토 · 설계 · 보완."
> 관련: [집_컴퓨터_화면_설계](집_컴퓨터_화면_설계.md)(모니터 두 쪽) · [카드보관함_설계](카드보관함_설계.md)(DEC-034 손으로 꽂기) · [UI_개편_설계](UI_개편_설계.md) 6 · 8번 판 · [가게_집_인테리어_설계](가게_집_인테리어_설계.md) 3-2 평면도
> 상태: **결정됨 (11-20, 추천안 그대로 — [DEC-042](../../DevLog/decisions/DEC-042-집-책상은-하나-판매-진열은-모니터로.md))**. 코드 구현됨, 씬 배치는 사용자(맵 수정 도구).
> 구현하며 바뀐 것: Q4 판매 · 진열 판을 **위아래 → 좌우**로 (위아래면 1.58m라 모니터 0.9m에 안 들어감). Q5 자동 넘김은 `BinderToComputer`를 따로 두지 않고 `SalesShowcasePage`가 함께 함 (같은 `CardSelected` 이벤트를 이미 받음).

## 3. B안 모양
### 3-1. 평면도 (뒤 벽, 위쪽이 +Z)
```
 z=2.0  ┏━━━━━━━━━━━━━━━━━━━━━━━━━ 뒤 벽 ━━━━━━━━━━━━━━━━━━━━━━━━━━┓
        ┃ [미니 주방: 싱크 · 냉장고]      ┌ 카드 보관함 (벽, 모니터 위) ┐   ┃
        ┃  (빈 바인더 책상 자리, Q3)     ╔═══ 긴 책상 하나 (약 2.0m) ═══╗ ┃
        ┃                                ║ 📖 바인더   │ 🖥 모니터     ║ ┃
        ┃                                ║ (펼침, 기울임) │ ⌨          ║ ┃
        ┃                                ╚═══════════════════════════╝ ┃
        ┃                                          🪑 의자 하나          ┃
```
- 책상: 지금 두 책상 자리 대신 **뒤 벽 오른쪽에 긴 책상 하나** (`OfficeTable` 두 개를 붙이거나 `PC_Table` + `OfficeTable`을 한 몸처럼 — 에셋은 Q2). 의자 하나(`Chair_Binder` 삭제).
- 바인더: 책상 **왼쪽 절반**에 펼친 바인더처럼 비스듬히(지금 20° → 35~45°로 더 눕혀 "책상 위 책" 느낌). 표지 소켓("여기에 놓으면 보관")은 바인더 바로 왼쪽 책상 위.
- 모니터: 책상 **오른쪽 절반**. 바인더와 겹쳐 레이가 막히지 않도록 바인더 위 끝 < 모니터 아래 끝, 또는 좌우로 떨어뜨림.
- 카드 보관함: 지금대로 모니터 위 벽 (`CardCaseAnchor`). 바인더 · 모니터 · 보관함이 의자 앞에서 한눈에.

### 3-2. 모니터 쪽 (집_컴퓨터_화면_설계를 3장으로)
```
[ 커뮤니티 ]  [ 슬라임마켓 ]  [ 판매 · 진열 ]      ● ○ ○
```
- **판매 · 진열 쪽** = 지금 `SalesPanel`(판매 등록 · 즉시 판매 · 등록 목록) + `ShowcasePanel`(진열장에 세우기 · 내리기)을 한 쪽에 위아래로. "가게 판매 목록을 PC로 올린다"는 느낌(TCG Card Shop Simulator의 PC 가격 화면).
- 바인더에서 카드를 고르면(트리거) 모니터가 **자동으로 판매 · 진열 쪽으로 넘어감** + 고른 카드 그림 · 이름 · 오늘 값 · 내일 인기(★) 한 줄. Q5
- 커뮤니티 쪽의 "내일 인기 속성"을 판매 쪽 위에도 한 줄로 → 쪽을 오가지 않고 판단.
- 진열 흐름(DEC-034)은 그대로: [진열장에 세우기] → 카드가 **바인더 위에** 떠오름 → 손으로 집어 위 벽 보관함에 꽂음.

### 3-3. 비는 자리 (지금 바인더 책상 · 의자)
원룸에 있을 법한 것으로 채움 — Q3. 추천은 **미니 주방**(싱크대 + 작은 냉장고, `LowPolyInterior/Prefabs/Kitchen`에 있음): 원룸 느낌이 가장 크게 나고, 나중에 "아침 커피 · 컵라면" 같은 꾸미기 · 혼잣말 거리로 쓸 수 있음. 효과는 없음.

## 6. 위험 · 확인할 것
- **레이 막힘**: 바인더 판이 모니터 앞에 있으면 모니터 버튼을 누를 때 바인더 판(캔버스)이 레이를 먼저 받음 → 좌우로 떼어 놓거나 높이로 겹치지 않게.
- **모니터 판매 쪽 글자 크기**: 의자 앞(약 0.7m)에서는 충분, 방 가운데(2.6m)에서는 작음 → 판매는 책상 앞에서 하는 일이라 괜찮음. Play로 확인.
- **자동 넘김이 거슬릴 수 있음**: 마켓을 보다가 바인더를 누르면 쪽이 바뀜 → 판매 쪽으로 넘긴 뒤 다시 원래 쪽으로 가기 쉬움(탭). Q5에서 정함.
- **바인더를 더 눕히면** 서서 볼 때 칸이 납작해 보일 수 있음 → 35~45°에서 Play로 맞춤.
