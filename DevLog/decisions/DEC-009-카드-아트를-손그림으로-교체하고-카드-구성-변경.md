## 문제
카드 아트 50장 가운데 일부는 Gemini로 만들어 두었고(프로젝트 31장 + 따로 생성한 14장), 나머지는 비어 있었다. 사용자의 아내가 카드 아트를 직접 그려 주기로 했는데, AI 생성 이미지를 매우 싫어해서 50장을 모두 직접 그리겠다고 했다. 그래서 다음을 정해야 했다.
- 그림을 그릴 사람에게 넘길 요청서의 내용과 규격
- 카드 분량을 줄일지
- 마음에 들지 않는 슬라임 컨셉과 간식 카드를 어떻게 바꿀지

## 선택지

### 1) 분량
| | A안: 그림만 줄이기 | B안: 등급당 1장 (35장) | C안: 50장 유지 + 컨셉 단순화 |
|---|---|---|---|
| 방법 | 카드 50장 유지, 노말~수퍼레어 배경은 셰이더 그라데이션 | 속성마다 등급별 1장 | 카드 수는 그대로 두고 그리기 쉽게 내용 조절 |
| 장점 | 데이터·밸런스 그대로 | 그림 수가 크게 줆 | 데이터·확률·테스트 그대로 |
| 단점 | 그림은 여전히 많음 | 중복이 잦아져 경제·도감 밸런스 재조정 필요 | 그림 수가 가장 많음 |

### 2) 레이어
| | 한 장짜리 그림 | 한 장으로 그리되 캐릭터·배경을 PNG 2개로 내보냄 |
|---|---|---|
| 장점 | 그리는 사람이 가장 편함 | 카드 셰이더의 패럴랙스와 레전더리 팝아웃 유지. 추가로 그릴 것은 없음 |
| 단점 | 입체 효과가 사라짐 | 내보내기 단계가 하나 늘고, 캐릭터 뒤 배경도 칠해야 함 |

### 3) "제거" 요청 처리
| | 카드를 빼기 | ID는 그대로 두고 이름·컨셉만 교체 |
|---|---|---|
| 장점 | 그릴 양이 줆 | 데이터 검사(등급별 장수), 확률표, 테스트 수정 없음 |
| 단점 | 불 수퍼레어 0장, 물 레어 0장이 되어 등급 구성이 깨짐 | `cards.csv`의 이름만 바뀜 (Unity에서 CSV 다시 불러오기 필요) |

### 4) 간식 대체
슬라임 알 / 젤리 결정(코어) / 병에 든 슬라임 세 가지를 검토했다.

## 고른 것과 이유
- **분량**: 50장 유지, 그리기 쉽게 컨셉을 조절(C안). 그림을 그리는 사람이 50장을 다 그릴 수 있다고 했다.
- **레이어**: 그림은 한 장, 저장만 캐릭터와 배경 PNG 2개 (Claude 제안). 배경은 그리는 사람이 직접 그리거나 가져올 예정이라 "배경을 별도 그림으로 나누지 않음"이 사용자의 요청이었다.
- **"제거" 처리**: ID 유지·컨셉 교체 (Claude 제안). 바뀐 카드:
  - 불: 처음에는 F-N3 고추, F-R1 뿔 하나, F-SR 불꽃 혜성으로 고쳤다가, 아래 "속성별 테마"로 다시 구성
  - **속성별 테마** (사용자가 "다른 속성도 한 테마에 맞추자"고 해서 정함. Claude가 속성마다 2~3안을 내고 사용자가 고름·수정):
    - 불 = **작은 불씨가 큰 불길로**: 촛불·숯불·노을 → 모닥불·화산뿔 → 불꽃 혜성 → 용암 군주 → 태양 거신. 처음에는 Claude 추천 "따뜻한 불"(랜턴·불꽃놀이·벽난로 지기)로 정했으나, 사용자가 "남성 플레이어도 즐길 수 있게 공격적·남성적인 슬라임이 있어야 한다"며 다시 정함. 노말은 포근하고 레어부터 강해지는 A안(Claude 제안)을 채택. F-N3는 Claude가 성냥을 냈으나 촛불과 비슷하다는 사용자 지적으로 노을 슬라임으로 바꿈
    - 땅 = **보석과 동굴**(Claude 추천은 숲속 친구들이었으나 사용자가 보석과 동굴을 고르고 8장 목록도 직접 정함): 진흙·조약돌·모래 → 수정·광부 → 강철 → 보석 군주 → 산맥 거신
    - 공기 = **자연 속 날아다니는 것**(Claude의 "하늘을 나는 것들" 안은 종이비행기·연·열기구 같은 인공물이 섞여 있었고, 사용자가 자연 기반으로 고침): 솜구름·민들레 홀씨·단풍씨앗 → 깃털·나비 날개 → 회오리 → 천공 수호자 → 하늘고래
    - 다섯 속성의 분위기: 불 포근함에서 용맹함으로(남성적인 카드 담당), 물 우아함, 땅 보석 탐험, 공기 자연의 비행, 무속성 가족
  - 물(여성스러운 디자인으로 통일, 사용자 결정): W-N3 진주, W-R1 해파리 드레스, W-R2 조개 머리핀, W-SR 물의 무희, W-U 산호 공주(사용자 아이디어), W-L 심해 여왕(기존 W-U 디자인을 승격, 사용자 결정)
  - 무속성: 분홍 또는 베이지·무색 계열로 통일(사용자 결정). N-U 프리즘 현자는 마법 판타지 쪽이라 기본 슬라임 느낌과 멀다는 사용자 지적에 따라 **슬라임 대모**(알 둥지를 품은 베이지 슬라임)로 교체. Claude가 대안 세 가지(대모·벚꽃 귀족·장로)를 냈고 사용자가 대모를 골랐다. 슬라임 알 카드와 이어지고, 무속성을 아기 삼형제 → 분열 → 대모 → 원초의 슬라임으로 묶는 "가족" 테마가 생긴다
  - 필드: FD-SR 반딧불 이끼 동굴, FD-U 푸른 산호섬, FD-L 슬라임 천국(사용자 결정). 먼 거리의 작은 슬라임은 허용
- **간식 → 슬라임 알** (사용자 결정. 간식은 게임과 어울리지 않는다는 판단). 말랑한 알 → 물방울무늬 알 → 빛나는 알 → 황금 알 → 별빛 알. 코드의 `CardKind.Snack`과 ID 접두 `SN`은 직렬화와 테스트 호환을 위해 그대로 두었다.
- **얼굴 규칙 예외**: 산호 공주와 심해 여왕만 짧은 속눈썹 허용(사용자 결정).
- **N-L**: 세로로 긴 몸의 한 장짜리 일러스트(DEC-003) 대신 다른 레전더리처럼 돔형 몸 + 레이어 2개로 되돌림(Claude 추천을 반영해 요청서에 적음).
- 이미 만든 이미지가 있는 슬라임은 그 이미지를 보고 설명을 다시 썼다. 그리는 사람은 AI 이미지를 보지 않고 글만으로 그린다.

## 치른 대가 (Trade-off)
- 이미 만든 AI 아트 45장과 Gemini 프롬프트 가이드의 생산 공정은 더 쓰지 않는다.
- 50장을 사람이 그리므로 일정이 그림 완성 속도에 달린다. 그림이 오기 전까지 카드는 지금 아트나 빈 칸으로 보인다.
- 코드 이름(`Snack`, `SN-`)과 게임 안 이름(슬라임 알)이 달라졌다.
