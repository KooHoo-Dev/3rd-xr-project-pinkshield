## 문제
가게·집이 상자 블록아웃이라 "카드샵에서 일하고 집에 돌아가는" 느낌이 약했습니다. 실내 에셋(LowPolyInterior)을 VR(Quest) 기준으로 어떻게 쓸지, 창밖 풍경을 무엇으로 보여 줄지 정해야 했습니다.
Claude가 에셋을 분석해 설계서를 쓰고 결정 항목 9개(D1~D9)를 제안했고, 사용자가 검토해 정했습니다.

## 선택지 (주요 항목)
| 항목 | 검토한 안 | 고른 것 |
|---|---|---|
| D1 가게 크기 | A 7.5×5m(2.5m 모듈 그대로) / B 7.5×7.5m | **사용자 수정: 약 1.2배** → 껍데기(벽·바닥·천장)만 1.2배 = 9×6m, 천장 3m, 가구는 1배 |
| D2 조명 | A 실시간 / B Baked Indirect | A 실시간 (페이즈별 색 변화 유지) |
| D3·창밖 | 창밖 셰이더(WindowView) 가게·집 모두 / 가게 밖은 3D 거리 | **사용자 결정: 가게 밖은 PolygonCity(Synty) 3D 거리, 셰이더는 집 창만** |
| D6 URP 변환 | A MAIN.mat 셰이더를 Simple Lit로 교체 / B 동봉 URP 패키지 임포트 | A (코드 도구로 두 에셋 일괄 변환) |
| D7 배치 방식 | A 인테리어 프리팹 손배치 + 빌더는 인스턴스만 / B 빌더 코드로 전부 배치 | A (처음 배치는 코드로 생성, 이후 프리팹 모드에서 손으로 다듬음) |
| 기타 | D4 문짝 없는 입구, D5 슬라임 피규어·아크릴 스탠드 직접 제작, D8 팩 테이블 x -1.5, D9 낮은 비용 제안 먼저 | 모두 추천안 |
| 외부 에셋 | Anime Tokyo (타이틀 연출 문서의 가게 건물 후보) | **사용자 결정: 사용하지 않고 삭제**, 도시는 PolygonCity로 |

## 치른 대가 (Trade-off)
- 실시간 조명이라 간접광이 없어 실내가 다소 평평함 (나중에 베이크 시도 여지).
- 가게 밖이 실제 3D라 건물·인도 수십 개가 늘어남 (정적 배칭으로 대응, 실기기 측정 필요).
- 껍데기 1.2배로 출입구도 약 1.2×2.5m로 커짐.
- DEC-006(타이틀 = 녹화 영상 + 실시간 매치 컷)은 Anime Tokyo 거리를 전제로 했으므로, PolygonCity로 다시 찍어야 함.
