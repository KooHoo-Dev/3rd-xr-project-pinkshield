# DEC-034 · 진열장은 모니터 위 벽의 카드 보관함에 손으로 꽂는다 (DEC-023을 진열장에 한해 바꿈)

## 문제
- 체크 5-5 "책장 말고 카드 전용 보관함에 직접 집어서 놓고 싶다", 캡처 8: 책장 앞 받침의 카드가 **떠 있는** 것처럼 보임.
- 5-6 "모으는 경험을 잘 못 느낌" — 진열이 버튼 한 번이라 손으로 하는 일이 없음.
- 7-1 (J6) "진열장을 컴퓨터 모니터 위로".

## 선택지
| | A안 지금대로 | B안 손으로 꽂는 보관함 (설계서 추천 + 꺼내기는 다른 안 ②) | C안 바인더 칸을 그립으로 쥐어 바로 꺼내기 (설계서 Q1 추천) |
|---|---|---|---|
| 방법 | 패널 버튼 → 책장 앞 받침에 카드가 나타남 | 모니터 위 벽 나무 틀 · 홈 10칸, [진열장에 세우기] → 바인더 위에 카드가 떠오름 → 손으로 집어 칸에 꽂음. 꽂힌 카드는 손으로 다른 칸 · 바인더(내리기)로 | B안 + 바인더 칸 그립으로 실물 카드를 손에 쥠 |
| 장점 | 구현 끝 | 손으로 꽂는 맛, 카드가 홈에 꽂혀 떠 보이지 않음, 자리는 씬 앵커로 사용자가 옮김 | 가장 손 중심, 버튼도 없음 |
| 단점 | 피드백에서 불만 | 꺼내기는 아직 버튼 한 번 | 그립과 레이 클릭이 섞이는지 · 쥐어 주기 감도를 Play로 맞춰야 함 (사람 없이 밤에 못 함) |

## 고른 것과 이유
- **B안**. 사용자가 "그동안 내 선택을 분석해 성향 기준 최선안으로 모두 구현"을 요청(11-20 밤) → Claude가 설계서 추천안을 따르되, Play 감도 조정이 필요한 C안(J5-c)은 사람이 없는 밤에 확인할 수 없어 B안으로 줄임.
- 사용자 성향 근거(이 세션의 선택): 화면 UI보다 세상 속 물건, 손 상호작용 선호, 위치는 씬에서 옮기고 싶음(J3 메모 자리 피드백).
- 칸 판정은 소켓 대신 거리(종이봉투 · 쓰레기통과 같은 방식) — 소켓 반경 조정 없이 바로 동작.

## 치른 대가 (Trade-off)
- 꺼내기는 아직 버튼 → C안(바인더 그립)은 다음에.
- 책장 앞 진열대(`ShowcaseShelf`)는 지움. 책장은 비어 있음(책 모델 정리는 씬에서).
- 칸 번호를 따로 저장하지 않고 목록 순서 = 칸 순서(빈 칸 사이를 두고 꽂을 수 없음, 늘 앞에서부터).
