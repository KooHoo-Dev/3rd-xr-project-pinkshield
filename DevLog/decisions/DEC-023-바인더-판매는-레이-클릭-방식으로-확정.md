## 문제
확인 목록 B7(바인더 표지에 카드를 꽂으면 칸으로 날아감)을 확인하려 했으나, 판매 목록 카드를 잡을 수 없고 꽂는 기능이 실제로 쓰이지 않았음.

## 선택지
| | A안 | B안 |
|---|---|---|
| 방법 | 레이 클릭 UI로 확정, 꽂기 확인 항목 삭제 | 카드를 손으로 집어 바인더에 꽂는 기능을 새로 만듦 |
| 장점 | 이미 동작하는 UI, 작업 없음 | VR다운 손맛 |
| 단점 | 손으로 만지는 재미는 적음 | 잡기 · 소켓 · 판매 목록을 새로 만들어야 함 |

## 고른 것과 이유
A안 (사용자 결정). 이유: (채우기)

## 치른 대가 (Trade-off)
바인더 손 조작은 하지 않음. `BinderCoverSocket` 코드 정리 여부는 BinderView 나누기 때 판단.
