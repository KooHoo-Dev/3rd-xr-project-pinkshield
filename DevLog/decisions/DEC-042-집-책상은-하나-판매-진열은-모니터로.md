# DEC-042 · 집 책상은 하나 — 실물 바인더는 책상 위, 판매 · 진열은 모니터 세 번째 쪽으로

|---|---|
| 날짜 | 2026-11-20 |
| 상태 | 채택 · 코드 구현됨 (씬 배치 · Play · Quest 확인 전) |
| 관련 | [집_책상_하나로_설계](../../Assets/98.%20Doc/집_책상_하나로_설계.md) Q1~Q6, [DEC-034](DEC-034-진열장은-손으로-꽂는-카드-보관함으로.md) · [DEC-036](DEC-036-진열-버튼은-바로-칸에-꽂힌다.md) |

## 문제
- 원룸에 책상 두 개 + 의자 두 개(바인더 책상 · 컴퓨터 책상)가 사무실 같음.
- 판매는 "내일 인기 속성"을 보고 정하는데, 그 정보(모니터)와 판매 판(바인더 옆)이 2.4m 떨어진 다른 책상에 있음.
- 사용자 요청 (11-20): "바인더 UI도 PC UI에 포함시키는 게 어떨까?"

## 선택지
| | A. 바인더를 PC 화면 안으로 | B. 책상 하나 + 실물 바인더, 판매 · 진열은 PC | C. 책상만 합침 |
|---|---|---|---|
| 방법 | 모니터에 바인더 쪽. 실물 바인더 없음 | 긴 책상 왼쪽 바인더 + 오른쪽 모니터 [커뮤니티 · 마켓 · 판매 · 진열] | 판 3장을 컴퓨터 책상 옆으로 |
| 장점 | 한 화면에서 끝 | 원룸 느낌 + 한 자리에서 판단 + 손으로 모으는 맛 유지 | 일이 작음 |
| 단점 | 카드가 화면 글자가 됨 (5-6 피드백 · DEC-034 방향을 되돌림), 일이 큼 | 쪽 일반화 · 씬 배치가 필요 | 판 3장이 여전히 공중에 뜸 |

## 고른 것과 이유
- **B안**. 사용자가 설계서 Q1~Q6 추천안을 그대로 확정 (11-20).
  - Q2 긴 책상 하나(약 2m) · 의자 하나 / Q3 빈 자리는 미니 주방 / Q5 바인더에서 고르면 모니터가 판매 · 진열 쪽으로 넘어감 / Q6 표지 소켓은 바인더 옆 책상 위.
- 설계서의 추천 이유: 화면보다 물건, 손 상호작용(DEC-034 · J3) 방향과 맞고, "원룸에 책상 하나"와 "한 자리에서 판매 판단"을 둘 다 해결.

## 구현하며 바뀐 것
- **Q4 "한 쪽에 위아래로" → 한 쪽에 좌우로.** 판매 판(높이 0.82m) + 진열 판(0.76m)을 위아래로 쌓으면 1.58m라 모니터 높이(0.9m)에 안 들어감. 좌우로 두면 0.95배로 줄여 그대로 들어감(폭 0.84m < 1.3m). 쪽 수는 그대로 3장.

## 치른 대가 (Trade-off)
- 판매 · 진열 판이 모니터 한 쪽 안에 있어, 커뮤니티 · 마켓을 보다가 바인더에서 카드를 고르면 쪽이 넘어감 (다시 보려면 옆 버튼).
- 판 두 장은 0.95배로 조금 작아짐.
