# DEC-005 · "진열"을 "판매 등록"으로 용어 변경

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-17 |
| 상태 | 채택 (코드 반영 완료, Unity 확인 전) |
| 관련 | HANDOFF 플레이 피드백(2차), `EconomyConfig.minDisplayRarity` |
| 포트폴리오 | |

## 문제
테스터가 "진열"을 집 방 안 장식으로 착각함. 같은 단어로 가게 판매 등록(수퍼레어 이상)과 방 장식(새 기능, 벽장)을 모두 부르면 혼란이 커짐.

## 선택지
| | A안 | B안 |
|---|---|---|
| 방법 | "진열" 유지, 설명 추가 | 화면 문구·문서를 "판매 등록"으로, 방 장식은 "장식/전시"로 구분 |

## 고른 것과 이유
B안. 테스터의 실제 오해가 근거. 코드 식별자(`DisplayResult` 등)는 당장 바꾸지 않고 화면 문구와 문서만 변경.

## 치른 대가 (Trade-off)
코드 용어(Display)와 화면 용어(판매 등록)가 한동안 달라짐.
