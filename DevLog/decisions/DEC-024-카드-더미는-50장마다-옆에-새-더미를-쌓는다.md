# DEC-024 · 카드 더미는 50장마다 옆에 새 더미를 쌓는다

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-19 |
| 상태 | 채택 (이유 기입 전) |
| 관련 | `80a353b`, 작업계획 6장, AI 협업 후보 |
| 포트폴리오 | |

## 문제
카운터 더미가 60장이 되면 보관함으로 사라졌음. 사용자가 "계속 쌓으면 안 되나, 최적화 문제는?"을 물었음 (11-19 2차 피드백).

## 선택지
| | A안 | B안 |
|---|---|---|
| 방법 | 계속 한 더미에 쌓되 60장 넘으면 얇게 (Claude 첫 구현) | 50장마다 오른쪽 10cm 옆에 새 더미, 최대 4개 |
| 장점 | 구현 단순, 더미 하나 | 카드가 쌓인 양이 한눈에 보임, 높이가 무한히 높아지지 않음 |
| 단점 | 한 더미가 계속 높아짐 | 더미 관리(굳히기 · 보관) 코드 추가, 카운터 가로 공간 사용 |

## 고른 것과 이유
B안 (사용자가 A안 구현을 보고 바꿈). 성능 검토: 실제 카드 오브젝트는 지금 더미 최근 15장 + 다 찬 더미마다 1장, 나머지는 덩어리 하나라 장수와 거의 무관. 이유: (채우기)

## 치른 대가 (Trade-off)
4개가 다 차면 마지막 더미에 얇게 쌓음. 오른쪽 끝 더미가 봉투와 겹치는지는 Play 확인(G20).
