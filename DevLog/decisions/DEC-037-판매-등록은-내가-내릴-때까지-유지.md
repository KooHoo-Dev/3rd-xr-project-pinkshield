## 문제
- Quest 1차 플레이: "판매 등록이 매일 풀림". `HomePhase`가 집에 올 때마다 안 팔린 판매 등록 카드를 보유로 돌려놓아, 같은 카드를 매일 다시 등록해야 했음.

## 선택지
| | A안 내릴 때까지 유지 (설계서 추천) | B안 반환은 하되 "어제 목록 다시 등록" 버튼 |
|---|---|---|
| 방법 | 매일 반환 없앰, 마지막 날(최종 점수 직전)에만 반환. 판매 패널에 [모두 내리기] | 지금처럼 반환 + 버튼 하나로 어제 목록 복원 |
| 장점 | 할 일이 없어짐, 이미 있던 `ReturnUnsoldOnFinalDay` 그대로 씀 | 매일 다시 고를 기회가 그대로 |
| 단점 | 다시 고르려면 [모두 내리기] 또는 하나씩 취소 | 버튼이 늘고 결국 같은 일을 매일 누름 |

## 고른 것과 이유
- **A안**. 사용자가 설계서 Q2 추천안을 그대로 확정 (11-20).
- 설계서의 추천 이유: B안은 결국 같은 버튼을 매일 눌러야 함. 최종 점수에 카드 가치가 들어가는 규칙은 마지막 날 반환으로 지켜짐.

## 치른 대가 (Trade-off)
- 인기 속성이 바뀌어도 어제 등록한 카드가 그대로 남음 → 집에서 내일 인기(★)를 보고 직접 바꿔야 함.
- 무한 모드: 마지막 날이 없으므로 반환하지 않음 (7일차 공식 기록 때는 반환됨).
