## 문제
- 사용자 요청(11-20): 인기 속성을 1개 → 2개(1순위 · 2순위)로, 오름 폭을 다양하게(무한 모드 고려), "지난 플레이에서 갓팩도 뜨고 7000달러까지 모였는데 판매가가 괜찮은지".
- 분석에서 찾은 사실: 7000달러의 원인은 인기 속성이 아니라 **상자(90)를 열어 집에서 즉시 팔면 평균 약 235가 돌아오는 구조**. 개수 제한이 없어 하루 2.6배씩 불어남(시뮬레이션: "다 사서 다 팔기"만 해도 7일 가운데값 약 32,500). 랭크 기준(S 2800)도 의미가 없어진 상태.
- 같은 검토에서: 손님이 진열 카드 1장만 골라 판정하므로 판매 칸을 늘려도 수입이 늘지 않음, 점수의 카드 가치(기준가) 때문에 가구를 사면 점수가 크게 떨어짐.

## 선택지
| Q | 고른 것 (추천안) | 검토한 다른 안 |
|---|---|---|
| Q1 돈 복사 고리 | 등급별 **매입가 표**: 노멀 0.2(5장에 1) · 레어 1 · 수퍼레어 5 · 유니크 25 · 레전더리 100 → 상자 기대값 83 (< 90) | 상자 하루 입고 제한 / 둘 다 |
| Q2 2순위 배율 | 1순위 보너스의 절반 | 2순위 강도를 따로 뽑음 |
| Q3 강도 확률 | 소폭 ×1.3 30% · 상승 ×1.6 40% · 급등 ×2.0 22% · 폭등 ×3.0 8% | 폭등 5% |
| Q4 주기 안 날마다 배율 변화 | 바꾸지 않음 (먼저 단순하게) | 1일차 ×75% · 2일차 ×100% |
| Q5 인기 → 손님 수요 | 넣음 (고를 때 가중치, 구매 확률 ×1.3 / ×1.15) | 값만 바꿈 |
| Q6 무한 모드 하락 속성 | 연장 4일부터 (주기 1~3일 무작위, 폭등 확률 증가, "역대급" ×4.0도 함께) | 넣지 않음 / 처음부터 |
| Q7 점수의 카드 가치 | **매입가** ("지금 다 팔면 얼마") | 기준가 유지 / 기준가 절반 |
| Q8 손님 고르기 | 진열 카드를 **모두 둘러보고** 카드마다 구매 확률 × 0.4로 판정, 최대 1장 | 지금처럼 1장만 골라 판정 |
| Q9 가구 가격 · 효과 | DEC-040(14장 재설계)으로 대체 | 13-4 가격만 조정 |

## 고른 것과 이유
- **Q1~Q9 모두 추천안** — 사용자가 "추천안도 깔고"(11-20)로 확정.
- 추천 근거(Claude 설계, 시뮬레이션): 실제 TCG처럼 "팩을 까서 다 팔면 조금 손해, 대박 카드와 직접 판매가 이득"인 구조로 바꿔 돈 버는 실력이 진열 판매 · 인기 속성 맞추기로 가게 함. Q7 매입가 점수는 가구를 사도 점수가 손해 보지 않게 하고(가구 전부: 기준가면 −46%, 매입가면 +4%), Q8은 판매 칸 업그레이드가 실제 수입으로 이어지게 함(칸 4 → 6에서 하루 판매 120 → 153).
- 사용자가 덧붙인 것: "이 부분은 튜토리얼로 짚지 않으면 쉽게 놓칠 것" → 튜토리얼 설계를 따로 세션으로 맡김.

## 치른 대가 (Trade-off)
- 즉시 판매로 받는 돈이 크게 줄어듦 (상자 하나 다 팔면 235 → 83). 지난 플레이처럼 돈을 크게 모으는 맛은 사라짐.
- 레전더리 1장이 최종 점수에서 500이 아니라 100 → 정산 판에는 기준가(시세)를 함께 보여 주는 식으로 보완해야 함.
- 점수 크기가 바뀌어 랭크 기준(S · A · B)을 다시 정해야 함 (출발점 대략 S 1,500 · A 1,200 · B 900, E5 시뮬레이터로 확정).
- `CardElement popular`를 받던 약 15곳을 `MarketDay`로 바꾸는 큰 수정.
- 시뮬레이션은 단순화한 플레이어 모델 — 확정은 E5 `EconomySimulator`(실제 규칙 코드)와 Play로.
