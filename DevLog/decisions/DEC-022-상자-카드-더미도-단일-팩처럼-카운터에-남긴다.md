# DEC-022 · 상자 카드 더미도 단일 팩처럼 카운터에 남긴다

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-19 |
| 상태 | 채택 (이유 기입 전) |
| 관련 | `80a353b`, BUG 없음, 확인 목록 B3 · B4 · G3 |
| 포트폴리오 | |

## 문제
상자를 다 넘기면 결과판이 뜰 때 상자 카드 더미가 사라졌음 (원래 동작). Play 확인 목록의 기대 동작(위 3장 실제 카드 + 덩어리가 남음)이 실제와 달라 결정이 필요했음.

## 선택지
| | A안 | B안 |
|---|---|---|
| 방법 | 단일 팩처럼 카운터에 남김 (잡아 볼 수 있고, 이어서 연 팩은 그 위에, 퇴근 때 보관함으로) | 지금처럼 치우고 하이라이트 5장만 남김 |
| 장점 | 연 카드가 쌓이는 손맛이 단일 팩과 같음 | 단순, 카운터가 깨끗 |
| 단점 | 상자(얇게) · 단일 팩(보통) 높이 계산을 나눠야 함 | 상자 카드는 눈에서 바로 사라짐 |

## 고른 것과 이유
A안 (사용자 결정). 이유: (채우기)

## 치른 대가 (Trade-off)
카운터가 더 붐빔 → 이후 DEC-024(50장마다 새 더미)로 이어짐.
