## 문제
Quest 시연 후 피드백: 카드를 뒤집기 전에 등급 색이 먼저 보여 어떤 카드인지 알 수 있고, 그래서 한 장씩 넘기는 기대감이 줄어든다. 또 앞서 정한 갓팩 전용 연출·유니크 이상 스킵 불가 규칙을 바꾸고 싶다는 의견.

## 선택지
| | A안 (유지) | B안 (사용자 피드백대로 변경) |
|---|---|---|
| 등급 색 | 뒤집기 전에도 색으로 힌트 | 뒤집는 순간까지 숨김 |
| 갓팩 | 전용 5장 동시 공개 | 일반 팩과 같은 한 장씩 |
| 스킵 | 유니크 이상은 스킵 제외 | 꾹 누르면 전 등급 스킵 |
| 레전더리 | 카메라 셰이크 + 큰 폭죽 (요청 원안) | 폭죽 확대 + 카드·더미 흔들림 + 컨트롤러 진동 (셰이크 대체) |

## 고른 것과 이유
B안. 등급 색 숨김은 "기대감이 줄어든다"는 시연 피드백이 근거. 카메라 셰이크는 VR 멀미 우려(Claude 제안, 헤드락 UI를 피한 것과 같은 계열)로 카드 흔들림·진동으로 대체하기로 사용자가 동의. 갓팩 통일·전 등급 스킵의 사용자 판단 근거는 별도로 기록되지 않음(피드백 원문만 있음).
- 수퍼레어~유니크 이펙트는 하나로 통일.

## 치른 대가 (Trade-off)
- 유니크·레전더리를 의도치 않게 넘겨 놓칠 수 있음.
- 갓팩의 특별함이 연출이 아닌 결과(카드 구성)로만 남음.

## 다시 보면 (나중에 채움)

## 수정 (같은 날, Quest 확인 후)
- 카드 **뒤집기 연출은 눈이 아파서 취소**, 기존(앞면으로 쌓아 한 장씩 넘기기) 방식으로 되돌림.
- 사용자가 원래 요청한 것은 "팩을 뜯을 때 나오는 하얀 빈 카드(빛줄기 판) 제거"였음 → AI가 "등급 색 노출"로 해석해 뒤집기까지 넣었던 것(오해). 빛줄기 판은 제거.
- 왼손 트리거 돌려보기(놓으면 제자리로)는 제거 — 기존처럼 카드를 잡아 놓으며 볼 수 있는 방식이 더 좋다는 피드백. 결과함 단계에서 더미 카드를 잡을 수 있게 함.
- 뜯긴 빈 팩이 작아지며 사라져 실감이 덜함 → 크기는 유지한 채 비틀리며 아래로 떨어지게 변경.
