# DEC-021 · 무료 팩은 퇴근 후 계산대 위 그 팩을 직접 연다

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-19 |
| 상태 | 채택 (이유 기입 전) |
| 관련 | `80a353b`, 작업계획 2장 |
| 포트폴리오 | |

## 문제
영업 중 도둑에게서 지키는 계산대 무료 팩이 퇴근하면 사라지고, 실제로는 "다음에 사는 선반 팩 1개가 0원"으로 처리돼 플레이어가 버그로 느꼈음 (11-19 플레이 피드백 I).

## 선택지
| | A안 | B안 |
|---|---|---|
| 방법 | 퇴근 후 받침 위에 열 수 있는 팩을 놓고 잡아서 자르면 무료로 열림. 선반 팩은 늘 유료 | 지금 방식 유지 + 팩 진열대에 "무료 1개" 표시 |
| 장점 | 지킨 팩을 직접 여는 보상이 눈에 보임, 도둑 시스템과 이어짐 | 코드 변경 적음 |
| 단점 | 새 클래스(`FreePackOffer`) · 규칙(`TryOpenFree`) 추가 | 보이던 팩이 사라지는 어색함은 남음 |

## 고른 것과 이유
A안 (Claude 추천, 사용자 "제안한대로 진행"). 이유: (채우기)

## 치른 대가 (Trade-off)
선반 팩을 먼저 사도 무료가 적용되던 편의는 없어짐 — 무료 팩은 계산대 그 팩으로만.
