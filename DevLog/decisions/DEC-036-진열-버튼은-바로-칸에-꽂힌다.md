## 문제
- Quest 1차 플레이: "진열장에 놓아도 안 보이고 매일 풀림".
- DEC-034 흐름(버튼 → 바인더 위에 떠오름 → 손으로 집어 꽂아야 저장)에서 손으로 꽂는 단계를 지나치면 진열이 저장되지 않음.

## 선택지
| | A안 지금대로 (손으로 꽂아야 저장) | B안 버튼 = 바로 꽂힘 (설계서 추천) |
|---|---|---|
| 방법 | [진열장에 세우기] → 바인더 위 카드 → 손으로 보관함에 | [진열장에 세우기] → 첫 빈 칸에 바로 꽂힘, 바인더에서 칸으로 0.5초 날아감 + 소리 + 진동 |
| 장점 | 손으로 꽂는 맛 | 데이터가 버튼에서 확정 — 놓칠 단계가 없음, 날아가는 연출로 "어디에 갔는지" 보임 |
| 단점 | 플레이어가 꽂는 단계를 모르면 고장처럼 보임 (실제로 일어남) | 꺼내 꽂는 손맛이 줄어듦 (옮기기 · 내리기는 손으로 남음) |

## 고른 것과 이유
- **B안**. 사용자가 설계서 Q9 추천안을 그대로 확정 (11-20).
- 설계서의 추천 이유: 플레이에서 꽂는 단계를 지나쳐 기능이 안 되는 것처럼 보였음. 손으로 하는 일은 옮기기 · 바인더 위로 내리기에 남겨 손 상호작용 방향(DEC-034)은 유지.

## 치른 대가 (Trade-off)
- 칸을 골라 꽂을 수 없음 — 늘 첫 빈 칸 (원하는 칸은 손으로 옮김).
- 설계서에 있던 "처음 진열하면 한 번만 '모니터 위 보관함에 세웠어요' 안내"는 따로 만들지 않고, 패널 문구가 매번 같은 말을 함.
