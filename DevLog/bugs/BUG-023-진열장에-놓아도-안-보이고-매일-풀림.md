# BUG-023 · 진열장에 놓아도 안 보이고 매일 풀림 (손으로 꽂지 않은 카드가 사라짐)

## 1. 증상 (문제)
- **기대**: [진열장에 세우기]를 누르면 모니터 위 보관함에 카드가 보이고 다음 날에도 남음.
- **실제**: 놓아도 안 보이고, 다음 날 또 풀려 있음 (사용자 플레이 메모).
- 스크린샷 없음 (Quest 플레이 메모).

## 2. 재현 단계 (추정)
1. 집에서 바인더 카드를 고르고 진열 패널 [진열장에 세우기]
2. 바인더 위 0.3m에 떠오른 카드를 보관함에 꽂지 않고(또는 못 보고) 침대로 감
3. 다음 날 보관함이 비어 있음

## 3. 콘솔 로그
```text
(오류 없음)
```

## 4. 원인 (추정)
- DEC-034 흐름: ① [진열장에 세우기] → ② 카드가 **바인더 위에 떠오르기만** 함 → ③ 손으로 집어 보관함 칸에 꽂아야 진열(데이터)이 바뀜.
- ③을 안 하면 보관함은 비어 있고, 집을 나가면 떠 있던 카드가 사라짐(`CardCase.OnDisable`) → "놓아도 안 보이고 매일 풀림"과 증상이 맞음.
- 보관함이 모니터 위(틀 위 끝 약 2.2m)라 눈에 잘 안 띄는 것도 겹친 것으로 봄.
- 진열 목록(`GameSession.Showcase`)을 지우는 코드는 없음을 확인 (데이터가 날마다 지워지는 것은 아님).

## 5. 해결
- `CardCase.Place`: 버튼을 누르면 **바로 첫 빈 칸에 꽂힘**(데이터는 누르는 순간 확정). 카드가 바인더 위에서 그 칸으로 0.5초 날아감 + 꽂는 소리 + 양손 진동.
- 손으로 하는 일은 옮기기 · 바인더 위로 내리기만 남김 (그 코드는 그대로). 꺼내기(Loose) 코드 삭제 — `CardCase` 295 → 269줄.
- 패널 문구: "○○을(를) 모니터 위 보관함에 세웠어요!", 아래 안내 "보관함 카드는 손으로 옮기거나 바인더 위로 내려요".
- DEC-036 (DEC-034의 "꺼내기를 손으로"를 바꿈).

## 6. 결과
- EditMode 테스트 351개 모두 통과 (보관함 자체의 자동 테스트는 없음).
- Quest 확인 전: [작업보고_11-20_플레이피드백구현](../작업보고_11-20_플레이피드백구현.md) 확인 목록.

## 7. AI 협업
- 내가 한 일: 플레이 메모. 설계서 Q9에서 "버튼 = 바로 꽂힘" 확정.
- AI가 제안한 것: 코드 흐름으로 "꽂지 않으면 데이터가 안 바뀜"을 원인으로 추정, 바로 꽂히고 날아가는 연출로 손맛 일부를 남기는 안.
- 받아들임 / 고침 / 거절 — 이유: 추천안 그대로.
- 관련 대화: 2026-11-20 플레이 피드백 구현 세션

## 8. 배운 점
- 손 상호작용을 늘릴 때 "손으로 하지 않으면 결과가 저장되지 않는" 단계를 두면, 플레이어가 그 단계를 모르고 지나쳐 기능이 고장 난 것처럼 보임 → 데이터는 버튼에서 확정하고 손은 연출 · 정리에.
