# BUG-022 · 판매 등록이 매일 풀림 (집에 올 때마다 모두 돌려놓음)

| 항목 | 값 |
|---|---|
| 상태 | 해결 (Play · Quest 확인 전) |
| 심각도 | 보통 (매일 같은 카드를 다시 등록해야 함) |
| 발견 | 2026-11-20 (Quest 1차 플레이) |
| 해결 | 2026-11-20 |
| 씬 / 환경 | Shop · Quest 실기기 |
| 발견 커밋 | `c38e339` (설계서 B3) |
| 해결 커밋 | `59544ec` |
| 포트폴리오 | |

## 1. 증상 (문제)
- **기대**: 판매 등록한 카드는 팔리거나 내가 내릴 때까지 등록 상태로 남음.
- **실제**: 다음 날 집에 오면 판매 등록 목록이 비어 있음.
- 스크린샷 없음 (Quest 플레이 메모).

## 2. 재현 단계
1. 집에서 수퍼레어 이상 카드를 판매 등록
2. 다음 날 영업에서 안 팔림
3. 퇴근 → 집: 판매 등록 목록이 비고 카드는 보유로 돌아와 있음

재현율: 항상 (의도된 동작이었음)

## 3. 콘솔 로그
```text
[Phase] 안 팔린 진열 카드 N장을 집으로 가져옴
```

## 4. 원인
- `HomePhase.Enter`가 `SalesRules.ReturnUnsold`로 안 팔린 판매 등록 카드를 **매일 일부러** 보유 목록으로 돌려놓았음.
- 시연 피드백 때 "집에서 다시 고를 수 있게" 넣은 동작이 지금은 불편함이 됨 (코드 버그가 아니라 설계 문제).

## 5. 해결
- 매일 반환을 없앰. 반환은 마지막 날(최종 점수 직전)에만 — 이미 있던 `ReturnUnsoldOnFinalDay` (DEC-037).
- 판매 패널에 **[모두 내리기]** 추가 (씬 판을 다시 빌드하지 않도록 [모두 팔기] 버튼을 런타임에 복제해 "판매 등록 중" 제목 줄 오른쪽에).

## 6. 결과
- EditMode 테스트 351개 모두 통과. 집 도착 반환을 기대하는 테스트는 없었음 (마지막 날 반환 테스트 2개는 그대로 통과).
- Quest 확인 전: [작업보고_11-20_플레이피드백구현](../작업보고_11-20_플레이피드백구현.md) 확인 목록.

## 7. AI 협업
- 내가 한 일: 플레이 메모 "판매 등록이 매일 풀림". 설계서 Q2에서 A안(내릴 때까지 유지) 확정.
- AI가 제안한 것: 원인이 버그가 아니라 예전 시연 피드백으로 넣은 동작임을 찾고 A · B안 비교.
- 받아들임 / 고침 / 거절 — 이유: 추천 A안 그대로.
- 관련 대화: 2026-11-20 플레이 피드백 구현 세션

## 8. 배운 점
- 피드백으로 넣은 편의 동작도 다른 기능(판매 등록 칸 · 업그레이드)이 늘면 불편으로 바뀔 수 있음 → 결정 기록(DEC)으로 남겨 두면 나중에 "왜 이렇게 했나"를 바로 찾음.
