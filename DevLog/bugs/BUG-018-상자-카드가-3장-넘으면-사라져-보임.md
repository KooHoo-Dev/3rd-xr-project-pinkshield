## 1. 증상 (문제)
- **기대**: 상자를 다 넘기면 카드 더미가 카운터에 쌓여 남음 (DEC-022).
- **실제**: 카드가 3장을 넘으면 사라지는 것처럼 보이고, 겹친 카드가 깜빡이기도 함.

before 사진 없음.

## 2. 재현 단계
1. 퇴근 전 상자(10팩)를 사서 엶
2. 카드를 넘기며 카운터 더미를 봄
3. 4장째부터 아래 카드가 안 보임

재현율: 항상

## 3. 콘솔 로그
```text
(없음)
```

## 4. 원인
버그라기보다 **표시 값이 "사라짐"으로 보이게 잡혀 있던 것**입니다.
- 상자 더미는 위에 진짜 카드를 **3장만** 남기고(`BoxPileVisible = 3`) 그 아래는 덩어리 하나로 바꿈. 덩어리가 장당 0.8mm로 얇고 색이 카드 옆면과 같아 "합쳐짐"이 아니라 "사라짐"으로 보임
- 상자 카드 간격(`BoxPileThickness` 0.8mm)이 실제 카드 두께(1.56mm, 크기 배율 포함)보다 얇아 카드끼리 겹쳐 깜빡임(z-fighting)

## 5. 해결
`Presentation/CounterPileView.cs:32 · 40` 값 2개만 바꿈:
- `BoxPileVisible` 3 → **15** (단일 팩 더미와 같게)
- `BoxPileThickness` 0.8mm → **2mm** (카드 두께 이상)

덩어리가 상자처럼 보이는 문제는 따로 D3(카드 더미 질감)에서.
