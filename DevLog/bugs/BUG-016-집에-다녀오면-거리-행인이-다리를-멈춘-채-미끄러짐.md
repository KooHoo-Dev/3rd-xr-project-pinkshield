## 1. 증상 (문제)
- **기대**: 가게 앞 거리 행인이 걷는 동작으로 지나감
- **실제**: 퇴근 뒤 바깥 사람이 다리 움직임 없이 정지된 자세로 이동함

(before 사진 없음)

## 2. 재현 단계
1. 하루 영업 → 퇴근(집) → 다음 날
2. 거리 행인이 서 있는 자세 그대로 미끄러짐

재현율: 항상

## 3. 콘솔 로그
```text
(오류 로그 없음)
```

## 4. 원인
`Customers/StreetLife.cs` `SpawnWalker`가 걷기 속도 파라미터(`Speed`)를 만들 때 한 번만 넣음. 집 페이즈에 `ZoneVisibility`가 거리 오브젝트를 껐다 켜는데, Animator는 다시 켜질 때 파라미터를 기본값(0)으로 초기화 → 대기 동작으로 이동.

## 5. 해결
`SetAnimatorSpeed`에서 매 프레임 `Speed`를 다시 넣고, `keepAnimatorStateOnDisable = true`.
