## 1. 증상 (문제)
- **기대**: 앉든 서든 눈높이가 매장 기준 1.6m에 맞춰짐.
- **실제**: 앉아서 플레이한 뒤 서서 빌드를 다시 실행하면 앉은 자세 기준으로 맞춰진 것처럼 시점이 낮음.
- 영상: 구글 드라이브 (사용자 촬영)

![before](../screenshots/BUG-008/before.png)

## 2. 재현 단계
1. Quest에서 앉아서 플레이
2. 일어선 뒤 앱을 다시 실행
3. 시점이 낮음

## 4. 원인
코드에서 찾은 원인 두 가지. 영상과 정확히 어느 쪽이 맞는지는 실기기 확인 전이라 **추정**입니다.
- ① `PlayerHeightCalibrator.Calibrate()`가 **XR Origin 루트**를 위아래로 옮겼음. 앉은 사람은 루트를 약 0.45m 올리게 되는데,
  Starter Assets 리그의 `GravityProvider`가 매 프레임 머리에서 아래로 구를 쏴서 땅을 찾음 → 발(루트)이 공중에 떠 있다고 보고 다시 바닥으로 떨어뜨림.
  결과적으로 위로 올린 보정은 사라지고 실제 앉은 키(낮은 시점)가 됨.
- ② 보정을 **앱 시작 1초 뒤 한 번만** 했음. Quest는 앱을 닫지 않고 이어서 실행하기도 해서 `Start()`가 다시 안 불릴 수 있고,
  자세를 바꾸거나 헤드셋을 벗었다 써도 다시 맞추지 않았음.

## 5. 해결
- 루트 대신 **Camera Offset**(`XROrigin.CameraFloorOffsetObject`) 높이를 바꿈. 발은 바닥에 그대로라 중력 판정과 싸우지 않음.
- 다시 맞추는 때 추가: 헤드셋 다시 쓸 때(`OnApplicationPause/Focus` 복귀) · 기기 재조정(`XRInputSubsystem.trackingOriginUpdated`).
- BUG-007 재발 방지: 고개가 수평(±25°)이고 머리 높이가 0.5초 동안 3cm 안에서 멈춰 있을 때만 맞춤. 6초 안에 못 찾으면 그냥 맞춤.

## 6. 결과
- 실기기 확인 전. 확인할 것: 앉아서 시작 → 서기 → 헤드셋 벗었다 쓰기 / 앱 다시 실행 / 스틱으로 이동한 뒤에도 눈높이 유지.
