## 2. 다른 PC 준비
1. **저장소 받기**: 이 PC에서 push한 뒤 `git pull` (오늘 커밋은 아직 push 전일 수 있음 — `git log origin/main..main`으로 확인)
2. **Unity 6000.3.15f1** + Android Build Support(OpenJDK · SDK · NDK 포함) 설치. 다른 버전으로 열면 패키지·씬이 바뀔 수 있습니다.
3. 처음 열 때 `Library/`를 새로 만드느라 오래 걸립니다. XRI Starter Assets 샘플은 저장소에 들어 있어 따로 임포트하지 않아도 됩니다.
4. 열고 나서 확인
   - `Tools > CardShop > Validate Data` → 오류 0개 (경고 1건 "아트 누락"은 배경 그림이 아직 없어서 정상)
   - Test Runner(EditMode) → 48개 통과
   - `Assets/00. Scenes/Shop.unity`를 열고 Play
5. **Quest 연결**: 헤드셋 개발자 모드 · USB 디버깅 허용. adb가 `unauthorized`면 헤드셋 개발자 설정에서 USB 디버깅 권한을 취소하고, 다시 꽂아 **RSA 키 지문이 있는 창**에서 허용합니다.
   - 빠른 테스트: Quest Link / Air Link로 연결하고 에디터에서 Play
   - 빌드: `Tools > CardShop > Quest > Build APK (Development)` (처음 한 번은 `Apply Build Settings`)
6. **Claude 작업 환경** (저장소 밖이라 따로 챙길 것)
   - `/devlog` 스킬은 저장소 `.claude/skills/devlog/`에 있어 그대로 동작합니다.
   - 대화 기록 `~/claude-worklog`는 별도 저장소입니다. 다른 PC에도 clone하고 `install.py`로 설치해야 이어서 기록됩니다.
   - Claude 메모리(PC별 저장)에 있던 규칙 하나는 새 PC에서 다시 알려 줍니다: **"버그를 보고하면 고치기 전에 before 스크린샷(F9 / Shift+F9)부터 요청"**

## 3. 테스트하는 법 (지금 기준)
- 개봉은 **퇴근 후 페이즈에서만** 됩니다. 디버그 패널의 `퇴근 전으로 건너뛰기`를 누르고 테스트합니다.
- 팩 열기: **왼손 그립**으로 선반 팩을 잡으면 눈앞에 뜸 → **오른손 트리거**를 누른 채 윗부분 흰 선을 따라 그음(손끝 또는 레이저) → 70%면 개봉
- 카드 넘기기: **오른손 트리거**를 누를 때마다 맨 앞 카드가 카운터로 날아감
- 에디터 시뮬레이터(키보드·마우스): Shift를 누르고 있으면 왼손, 떼면 오른손으로 입력이 갑니다. "왼손 그립 유지 + 오른손 트리거"는 **빠른 동작 토글**(`` ` ``로 그립 선택 → Space로 켜기)로 그립을 켜 둔 뒤 오른손 트리거를 누릅니다.
- 원하는 결과 강제: 디버그 패널 `다음 팩: 갓팩 / 레전더리 확정 / 유니크 히트`
- 시점이 낮거나 높으면 디버그 패널 `눈높이 맞추기 (1.6m)`

## 7. 알아 둘 것
- MonoBehaviour는 **파일 하나에 클래스 하나, 파일 이름 = 클래스 이름**. 어기면 프리팹에서 조용히 Missing Script가 됩니다(BUG-001). 회귀 테스트 `PackPrefab_HasNoMissingScriptsAndOpenMethod`가 잡아 줍니다.
- Rigidbody가 있는 물체를 스크립트로 순간이동시킬 때는 `Teleport()`처럼 Transform과 Rigidbody를 **함께** 옮깁니다(BUG-003).
- `Shop.unity`는 `Tools > CardShop > Build Shop Scene`으로 다시 만들 수 있습니다. 씬에서 손으로 옮긴 위치는 빌더 코드(예: `PackTablePos`)에도 반영해야 다시 만들 때 사라지지 않습니다.
- `NotoSansKR-Regular SDF.asset`은 다이내믹 폰트라 새 글자를 쓰면 저절로 바뀝니다. 커밋에 섞여도 정상입니다.
- **카드 그림 누끼**: Gemini는 투명 PNG를 잘 못 만들고, 배경을 지워도 바닥 그림자가 불투명한 회색으로 남습니다. `DevLog/tools/card-nukki.ps1`
  - `-Mode dark`: 어두운 단색 배경(공기 속성) · `-Mode light`: 흰색·밝은 회색 배경 · `-Mode shadow`: 이미 투명한 그림의 그림자만
  - 결과는 먼저 `-OutDir`로 임시 폴더에 뽑아 어두운 배경 위에서 눈으로 확인한 뒤 `Char/`에 넣습니다. 그림마다 그림자 기준값 조정이 필요할 수 있습니다(스크립트 머리말에 지난번 값).
  - 파일 이름은 CSV id의 `-`를 `_`로 바꾼 `<ID>_char.png`. CSV의 `char` 열은 이미 이 이름이라 CSV는 고치지 않아도 됩니다.
- 버그 사진: Unity Play 중 Shift+F9 → `DevLog/screenshots/_inbox/`, Unity 밖은 Win+Shift+S 후 `DevLog/tools/devlog-paste.ps1`.

### 카드팩 오픈 시스템 추가 설계
- 카드팩을 모두 다 열었을 때 카드를 확인 하는 방법이 데스크에서 보여지는 게 아니라, 카드팩을 다 열면 카드팩 결과함 UI 에서 바로 확인 가능한 구조로 시스템 설계
- 깐 카드팩의 카드들은 책상 위에 차곡히 쌓이고, 플레이어가 오른쪽 트리거로 쌓인 카드팩을 내 카드백 보관함에 넣을 수 있다.
- 10팩 카드팩 열었을 때 텍스트로 보여지는 방식이 아니라, 열팩을 한번에 까는 모습을 보여주고 한장씩 넘기는 방식으로 연출 변경 (빠르게 넘기기는 오른쪽 컨트롤러 트리거 3초 이상 꾹 눌렀을때  가능)
