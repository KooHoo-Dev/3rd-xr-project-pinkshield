## 3. 씬에서 해 주실 것 (옮기기 메뉴)
- 사장님 메모 자리: **Tools > CardShop > Tutorial > Create Memo Anchor** → 만들어진 오브젝트를 옮기면 메모가 따라감 (없으면 봉투 오른쪽).
- 카드 보관함 자리: **Tools > CardShop > Home > Create Card Case Anchor** (없으면 모니터 위 벽).
- 거리 꾸미기 다시 만들기: **Tools > CardShop > Interior > Build Street Details (K1)** (씬에서 옮긴 소품은 처음 자리로 돌아감).
- 손님 성별 고치기: Tools > CardShop > Customers > Sort Customer Looks → **성별 (목소리)** 보기 (병렬 세션이 만든 Edit Customer Gender Age 창도 있음).
