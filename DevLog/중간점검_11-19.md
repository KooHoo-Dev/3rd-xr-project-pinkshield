`4d38140`에서 새로 만든 스크립트 8개는 `.meta` 파일이 **디스크에도 없습니다**(Unity를 아직 안 열어서 생기지 않은 것으로 보임). git 무시 규칙에 걸린 것은 아닙니다.

| 파일 |
|---|
| `Runtime/Cleanup/MopStation.cs` · `Runtime/Cleanup/StainSpot.cs` |
| `Runtime/Logic/MoneyText.cs` · `Runtime/Logic/StainRules.cs` |
| `Runtime/Presentation/BoxPackCounter.cs` · `Runtime/Tutorial/TutorialCaption.cs` |

- 할 일: 이 PC에서 Unity를 열어 `.meta`가 생기면 **바로 커밋**. 다른 PC가 먼저 열면 GUID가 서로 달라져 충돌할 수 있습니다.
- 새 컴포넌트는 모두 실행 중에 스스로 붙는 방식이라 씬이 GUID를 참조하지는 않습니다(씬 변경은 쓰레기 크기 · `resumeDelay` 같은 값뿐). 그래서 위험은 "충돌"이지 "씬 연결 끊김"은 아닙니다.
