## 5. 손님 동선 개편 (11-19 사진 기준) — 코드 완료, Build Shop Scene · Play 확인 전

**먼저 나눔** (큰_클래스_나누기_제안 2장): `CustomerDirector` 436 → 276줄. 부품 `CustomerBodyFactory`(몸) · `QueueMover`(줄 걷기, 계산대 줄과 대기 줄이 같이 씀) · `CheckoutLine`(계산대 줄: 인내 · 계산 · 떠나기) · `BrowseArea`(구매 자리 + 대기 줄) · `PatienceRules`(순수, 테스트 3개) · 등장 시각은 이미 있던 `SpawnClock`. `CustomerAgent.Init`은 Director 대신 `Func<bool> isPaused`를 받음.
**동선 테스트** (`ShopLayoutTests`): 대기 줄 · 구매 자리 길이 계산대 줄 · 다른 손님을 지나가지 않는지 2개 추가, 예전 "구경 자리가 차면 바로 줄" 길(`EnterToQueue`)은 없앰.
**남은 점**: 카드 도둑은 아직 예전 입장 길(문 → 앞벽 → 통로)이라 대기 줄 맨 앞 손님 옆을 스칠 수 있음(서로 비켜 걷기로 피함). Play에서 거슬리면 도둑 길도 줄 뒤 길로 옮김.


```
        창문 (z 4.2)
   ┌──────────────────────────────────────── 문(x 3.0)
   │  ← ← ← ← ← ← ← ← ← ← ← ← ← ← ← (입장: 창을 따라 왼쪽으로)
   │  [구매1]   [구매2]   [대기1] [대기2] [대기3] …   ← 대기 줄은 오른쪽으로 길어짐
   │  ┌──── 판매 진열대 ────┐
 ↓ │  └─────────────────────┘
   │  → → → → → → → → → → (진열대 앞을 지나 계산대 줄로)
   │                 [계산대 줄]
        카운터 · 플레이어 (z 0)
```
- 구매 자리 2칸: 진열대 **뒤**(창 쪽, z ≈ 3.15)에서 플레이어 쪽을 보고 구경 → 손님 얼굴이 보임
- 대기 자리: 구매 자리 2 오른쪽으로 창을 따라 차례로 줄섬. 구매 자리가 비면 맨 앞 대기 손님이 들어감
- 다 본 손님: 왼쪽으로 진열대 끝을 돌아 진열대 앞을 지나 계산대 줄 끝으로
- 구경하지 않는 손님(바로 계산)은 지금처럼 바로 계산대 줄로
- 대기 줄 칸 순서는 계산대 줄과 같은 규칙(`CustomerLine`, 테스트 있음)을 재사용, 길 계산은 `CustomerRoutes`(벽 · 진열대 통과 테스트 있음)에 추가
- 확인할 것: 진열대 왼쪽 끝(x ≈ −3.2)에 화분 같은 장식이 있으면 길을 옮겨야 함

| 말풍선 동그라미 잔재 | 위 3장 참고 |
