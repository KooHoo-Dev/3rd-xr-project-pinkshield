### U1. 🐞 판매 · 진열 창이 서 있는 방향에 따라 한 장만 보임 (체크 5-6, 옛 V3)
- **원인**: 두 창은 좌우로 떨어져 있어 겹치지 않음. 그런데 바탕화면(불투명 큰 판)과 창 사이 간격이 **2 ~ 4mm**뿐이고, 캔버스 **그리는 순서(sortingOrder)를 어디서도 정하지 않음**. 순서가 같으면 Unity는 "카메라에서 캔버스 가운데까지 거리"로 순서를 정하는데, 창은 가운데에서 ±20cm 떨어져 있어 **비스듬히 서면 먼 쪽 창이 바탕화면보다 먼저 그려져 덮임**. 가운데에 있는 커뮤니티 · 마켓 창은 그래서 멀쩡함.
- **고칠 내용**: 모니터 화면의 층마다 그리는 순서를 정함 — 바탕화면 0 · 쪽 바탕 1 · 창 2 · 창 안 카드 3 · 작업 표시줄 4 (`WorldUiKit.CreateCanvas`에 순서 값, `HomeComputer` · `SalesShowcasePage` · `ShowcasePanel`). 간격도 10mm로 벌려 이중으로 막음. 크기 **소**

### U2. 🐞 판매 창 글자 넘침 · 카드가 작고 아래가 빔 (사진 1)
- **원인**: 판매 판은 원래 "글자만 있는 판"으로 만들어졌는데, 4차에서 오른쪽에 카드 실물을 끼우며 글자 칸 폭만 줄임(273mm). 글자 26 고정 · 자동 줄임 없음 → 「회오리 슬라임 (수퍼레어)」가 두 줄, 「매입가 $5 · 가게에 올리면 $N+」도 두 줄 → 6줄이 칸(4줄 높이)을 넘쳐 **[판매 등록] 버튼 밑으로 잘림**. 아래 절반은 "판매 등록 중" 목록 자리라 등록한 카드가 없으면 텅 빔.
- **고칠 내용** (판 크기는 그대로, 안쪽 배치만):

```
┌ 판매  가게 판매대 · 매입 ─────── _ □ × ┐
│ ┌──────────┐  회오리 슬라임          │  ← 이름 (크게, 한 줄, 넘치면 자동 줄임)
│ │          │  ◆◆◆ 수퍼레어 · 보유 3장 │  ← 등급 기호 + 보유
│ │  카드    │  판매 등록 가능          │
│ │  (크게)  │                          │
│ └──────────┘  가게에 올리면 $N+       │  ← 작은 글씨 한 줄
│  [매입 $5] ← 카드 아래 노란 꼬리표    │
│ [        판매 등록 (분홍)         ]   │
│ [ 즉시 판매 ]  [ 레어 이하 모두 팔기 ] │
│ 판매 등록 칸 0/4 · 내 자산 $38        │
│ 판매 등록 중 (누르면 취소)  [모두 내리기]│
│  (비어 있으면) "아직 올린 카드가 없어요" │
└───────────────────────────────────────┘
```
  - 카드를 **왼쪽에 크게**(창 폭의 약 40%), 글자는 오른쪽 4줄 · 자동 줄임(최소 18). "매입가 $5"는 꼬리표와 겹치니 글자 줄에서 뺌.
  - 목록이 비면 안내 한 줄. 진열 창도 같은 규칙으로 점검. 크기 **소 ~ 중** (`SalesShowcasePage` · `SalesPanel`)
