## B. 잘 보이게 (UI)

### B1. 튜토리얼 자막 HUD — 가장 먼저 (2-5 "매우 불편", 캡처 2장)
캡처에서 본 문제:
1. **글자가 작고 흐림.** 연보라 글씨가 밝은 창밖 거리 위에 떠서 대비가 낮음. 사장님 이름표(주황)도 작음.
2. **위치가 대상 옆에 붙음.** 팩을 뜯을 때는 카드가 펼쳐지는 바로 그 자리에 떠서 가려짐(깊이 검사를 해서 카드 뒤로 숨음).
3. **두 줄의 역할이 섞임.** "사장님 말"과 "지금 할 일(오른손 트리거를 한 번 눌러 봐)"이 같은 크기 · 비슷한 색.
4. **주변 물건 이름표**(스캐너 · 결제 · 퇴근 · 봉투)도 흰 글씨만 있어서 배경에 묻힘.

제안 — **화면 아래 고정 자막 판** (새 클래스 `TutorialCaption`, 말풍선 `BossBubble`은 혼잣말 · 손님용으로 남김):

| 요소 | 내용 |
|---|---|
| 위치 | 눈 앞 1.0m, 눈높이보다 약 25° 아래. **천천히 따라오기**(머리를 15° 넘게 돌리면 0.4초에 걸쳐 따라옴) — 완전 고정은 멀미 때문에 피함 |
| 판 | 진보라 불투명 판 + 위쪽 분홍 띠(UI 테마 A). 폭 0.7m |
| 1줄: 말하는 사람 | 작은 칩 "사장님" / "혼잣말" |
| 2줄: 대사 | 지금보다 약 1.6배, 흰색 |
| 3줄: **할 일** | 노란색 굵은 글씨 + 버튼 그림 글자: 예) `[오른손 트리거] 한 번 눌러 넘기기` |
| 오른쪽 | 진행 점 ●●○○ (이 묶음에서 몇 번째 단계인지) |
| 항상 위에 | 카드 · 물건에 가려지지 않게 겹쳐 그리기(Overlay) 재질 |
| 나타날 때 | 0.2초 커지며 등장 + 짧은 "띵" + 양손 약한 진동 → 새 안내가 나온 걸 소리 없이도 알아챔 |
| 다 했을 때 | 할 일 줄이 초록 ✓로 바뀌고 0.6초 뒤 다음 단계 |

### B2. 손목 지갑 (피드백: 글씨 크게 · 이름 바꾸기)
- 글자 0.12 → **0.2**, 머리 글씨 55% → 80%, 판 크기도 함께.
- 이름 (결정: 11-19 2차 — "가지고 있는 돈 = 내 자산" 개념): 머리 글씨 **"내 자산"**, 숫자는 **원**.
- 원 단위 제안: 내부 숫자는 그대로 두고 **보여 줄 때만 ×500** (값 1개 `EconomyConfig.wonPerUnit`).

| | 내부 값 | 보이는 값 |
|---|---|---|
| 카드 팩 | 10 | 5,000원 |
| 상자(10팩) | 90 | 45,000원 |
| 하루 기본급 | 40 | 20,000원 |
| 노멀 카드 즉시 판매(예) | 1 | 500원 |

  실제 카드 팩 가격대라 "현실 알바"처럼 느껴지고, 업그레이드(E2) 가격도 "침대 35,000원"처럼 바로 감이 옴. 돈 글자를 쓰는 곳(정산 판 · 판매 판 · 선반 가격표 · 상자 버튼 "상자 열기(90)" · 최종 판)을 한 함수 `Money.Format`으로 모음.
- 최종 판의 "점수"와 별도로 **"총 자산 = 현금 + 방 가구 값 + 진열 카드 가치"** 를 보여 주면 업그레이드가 손해가 아니라 "자산을 바꾼 것"으로 느껴짐 (E2와 연결).
- 제안 보완: 돈이 바뀔 때(일당 · 팩 구매 · 판매) 손목이 **짧게 진동 + 숫자 +40 튀어 오름** → 손목을 보라는 신호가 됨(C의 "지갑 안내"와 연결).

### B3. 바인더에 돈 표시
바인더 판 위쪽 머리줄에 `알바 지갑 320` (판매 판에는 이미 있음). 판매하면 바로 늘어나는 게 보이게.

### B4. 상자 개봉 "N / 10 팩"
카드를 넘기는 동안 카드 더미 위에 `3 / 10 팩` 표시. 새 팩으로 넘어갈 때 숫자가 톡 바뀜. 새 클래스 `BoxPackCounter`, `CardRevealer`에는 "새 팩 시작" 알림 한 줄만.

### B5. 영업 시계판 + 마감 청소 알림 (피드백: 시계가 안 보임 · 청소 시간에 뭘 할지 모름)
지금 시계는 바늘만 있고 플레이어 뒤쪽 벽에 있음. 남은 시간 글자는 디버그 판에만 있음. 마감 청소 30초는 **릴리스 빌드에서 아무 안내가 없음**.

새 클래스 `ShopTimerBoard` — 계산대에 서면 정면(창문 위 벽)에 보이는 가게 전광판:

| 때 | 표시 |
|---|---|
| 영업 중 | 시계 그림 + `마감까지 1:05` (30초 남으면 분홍으로 깜빡) |
| 손님 마무리 | `마감! 남은 손님 2명` |
| **마감 청소** | `마감 청소 0:30 · 남은 곳 3` + 첫 시작 때 자막 HUD "손님이 다 갔다! 30초 안에 바닥 정리하자" + 남은 쓰레기에 외곽선 |
| 청소 끝 | `정리 완료! ✓` → 정산 |

### B6. 카운터 메모 (6-1 잘 안 읽힘)
바닥에 눕힌 20×13cm 종이 → **60° 세운 작은 메모판**, 글자 1.5배, 잘림 없이. 장기적으로는 메모 내용을 자막 HUD의 "오늘 새로 할 일"로 옮기고 메모판은 장식으로 둘 수 있음.

## C. 튜토리얼 다시 설계

### C1. 정지 · 잠그기 방식 바꾸기 (DEC-026 변경 → 새 결정 기록 DEC-028)
- 지금: 정지는 **첫 계산 · 첫 도둑 2곳**뿐. 나머지(쓰레기 · 팩 정리 · 마감 · 집)는 글자만 → 플레이어가 하던 일에 집중해서 안내를 놓침.
- 피드백 + 10장 결정: **"처음 하는 일"은 정지하고, 요청한 행동 말고는 잠근다(잠그기).**
- 바꿀 것:
  - 처음 나오는 업무 안내는 모두 **정지(Hold)**: 첫 쓰레기, 마감 청소 시작, 첫 흐트러진 팩, 판매 등록 카드 첫 손님, 첫 상자.
  - `outsideGrab` 기본값 **잠그기**. 잠긴 물건을 잡으려 하면 짧은 진동 + 자막 "지금은 이것부터!".
  - 정지 중에는 자막 HUD에 `⏸ 시간 멈춤 · 따라 해 보세요` 표시, 끝나면 `▶ 다시 시작!`.
  - 2번째부터는 정지 없이 짧은 말만(지금처럼).
- 남는 위험: 정지가 늘면 1일차가 길어짐 → 각 정지는 "행동 1개만" 시키고 바로 풀기. [안내 건너뛰기]는 그대로.

### C2. 외곽선 셰이더 + 조명 하이라이트 (캡처 2 제안 "조명으로 하이라이트")
지금은 주황 선 상자 + 바닥 고리(LineRenderer). 상자 모양이라 물건 모양과 안 맞고 주변을 가림.

| 층 | 방법 | Quest 부담 |
|---|---|---|
| 외곽선 | **뒤집은 껍데기(inverted hull) 외곽선 셰이더**를 물건에 두 번째 재질로 잠깐 붙임. 화면 후처리 없이 물건 모양 그대로 테두리 | 낮음 (그리기 1번 추가) |
| 조명 | 대상 위에 **가짜 조명 기둥**(위에서 내려오는 반투명 빛 원뿔) + 바닥 밝은 원. 정지 중 가게는 지금처럼 살짝 어둡게 → 대상만 "무대 조명" 받는 느낌 | 낮음 (진짜 실시간 조명은 쓰지 않음) |
| 맥박 | 외곽선 두께 · 밝기가 1초 주기로 커졌다 작아짐 | — |

색 규칙(한 곳에서 관리, `UiTheme`):
- **분홍**: 튜토리얼 대상 (지금 해야 할 것)
- **흰색 얇게**: 손 · 레이가 닿은 잡을 수 있는 물건 (피드백 "상호작용 오브젝트 아웃라인")
- **빨강**: 도둑 · 훔쳐 간 팩 (6-4 도둑 구분 보완)

주의: 카드 · 종이처럼 아주 얇은 물건은 껍데기 외곽선이 잘 안 보일 수 있어, 그런 물건은 크기를 살짝 키운 판으로 대신함.

### C3. 컨트롤러 버튼 빛내기 (제안)
캡처처럼 컨트롤러 모델이 보이므로, "오른손 트리거"를 말할 때 **실제 컨트롤러 모델의 트리거 부분을 분홍으로 깜빡임**. 글자를 읽지 않아도 어떤 버튼인지 알 수 있음. (XRI 컨트롤러 모델의 버튼 부위 이름을 찾아 재질 색만 바꿈.)

## D. 손맛 · 내용

### D1. 레이로 쥔 물건 거리 조절 (결정: 11-19 2차)
- 지금: 레이로 잡으면 물건이 **레이 끝에 매달린 채 거리 고정**. XRI 기본 "스틱으로 밀고 당기기"가 있는데 씬에서 꺼져 있음(`m_UseManipulationInput: 0`, 꺼 둔 이유는 기록이 없어 Play로 확인 필요).
- 사용자 결정: 손으로 순간 날아오게 하면 결국 쓰레기통까지 걸어가야 해서 **멀미가 나는 사람**이 생김 → **제자리에서 거리만 조절**해 멀리서 쓰레기통에 넣거나 팩을 꽂게 함. (AI 첫 제안 "잡으면 손으로 날아오기"를 사용자가 고침 → AI 협업 사례 후보)
- 방법:
  1. **스틱 위/아래 = 밀기/당기기**: XRI 기능을 켬. 물건을 레이로 쥔 손의 스틱은 그동안 이동 · 회전 대신 거리 조절에만 쓰임(XRI `ControllerInputActionManager`가 이미 처리). 회전(스틱 좌우)은 끄고 거리만 씀 — 실수로 물건이 빙글 도는 것 방지.
  2. **왼손 트리거 꾹 = 손 쪽으로 천천히 당기기** (요청한 버튼): 트리거에 자기 기능이 없는 물건만 — 쓰레기 · 팩 꽂이 팩 · 빗자루 · 손님 물건. **카드 · 카드 팩 · 스캐너는 제외**(트리거 = 넘기기 · 열기 · 찍기). 새 클래스 `RayPullAssist`.
  3. 당기는 속도는 일정(초당 약 1.5m), 손에서 0.15m 앞에서 멈춤.
- 튜토리얼: 첫 쓰레기 때 "레이로 잡고 스틱을 아래로 → 당겨지기 / 위로 → 멀어지기" 한 단계 추가.
- Play 확인: 물건을 쥔 손 반대쪽 스틱으로는 계속 이동 · 회전되는지, 놓으면 스틱이 원래대로 돌아오는지.

### D2. 상자 10팩 뜯기 연출에 좋은 카드 이펙트 (결정: 11-19 2차, 캡처 "10장 카드팩 오픈에서 수퍼레어 이상 카드 이펙트를 추가")
- 대상 장면: 상자를 열면 분홍 팩 10개가 한 줄로 서고, 한 번에 베어 윗부분이 뜯기는 연출(`BoxOpenEffect`).
- 지금은 DEC-004에 따라 이 장면에 등급 힌트가 **없음** → 10개가 똑같이 뜯겨 기대감이 없음. 사용자 결정으로 **DEC-004를 바꿈 → 새 결정 기록 DEC-029**.
- 연출(팩마다 그 팩에서 가장 좋은 등급 기준, 뜯긴 직후 왼쪽부터 0.12초 간격):

| 그 팩의 최고 등급 | 연출 |
|---|---|
| 레어 이하 | 그대로 (뜯긴 조각만 날아감) |
| 수퍼레어 · 유니크 | 팩 안에서 **금빛이 새어 나옴** + 작게 폭 튀어 오름 + 금색 폭죽(단일 팩 수퍼레어 폭죽 작은 판) |
| 레전더리 | 무지개빛 + 팩이 흔들리다 크게 튐 + 큰 폭죽 + 손 진동 |
| 갓팩 | 팩 10개가 아니라 그 팩만 앞으로 나오며 빛 기둥 (단일 갓팩 연출과 연결) |

- 효과가 있는 팩은 **모일 때(gather) 맨 뒤 = 카드 넘기기 때 마지막**으로 → "좋은 건 마지막" 규칙(G19)과 맞춤. 팩 위에 몇 번째 팩인지 작은 번호(B4와 같은 숫자).
- 빠진 것 보완: 캡처에서 10팩이 **그림 없는 분홍 사각형**이라 팩처럼 안 보임 → 단일 팩과 같은 팩 그림(SLIME PACK) 텍스처로.
- 카드를 한 장씩 넘길 때의 등급 연출은 이미 있음. 추가로 **길게 눌러 건너뛰기 중에도 수퍼레어 이상은 멈춰서 연출**(갓팩 방식과 같게).
- 코드: 연출은 새 클래스 `BoxPackRarityFx`, `BoxOpenEffect`(223줄)는 "팩 i가 뜯김" 순간에 알림만. 팩별 최고 등급은 이미 굴린 결과(`packs`)에서 계산하는 순수 함수 + 테스트.

### D3. 카드 더미 질감 (네모 상자처럼 보임)

### D4. 손님 외형별 대사 (나이 · 성별)
- 지금: 대사는 상황(입장 · 구경 · 기다림 …)만 보고 무작위. 손님 몸(성별)은 이미 알지만 대사에 안 넘김. **나이 정보는 없음**(손님 모델 115개, 노인 · 아이 전용 모델 없음).
- 설계: **손님 성격(Persona)** 층을 새로 둠.

| 성격 | 외형 기준 | 대사 예 | 행동(선택) |
|---|---|---|---|
| 손주 선물 어르신 | 나이 = 많음 | "손주가 슬라임 카드를 그렇게 좋아한다네" | 인내심 길게, 팩 위주 |
| 시세 궁금 어르신 | 나이 = 많음 | "옛날 카드도 비싸게 팔 수 있다던데…" | 판매 등록 카드에 관심 |
| 가챠 중독 청년 | 나이 = 젊음 | "이번엔 진짜 나온다. 한 박스만 더…" | 상자 · 여러 팩, 인내심 짧게 |
| 수집가 | 나이 = 중간 | "레전더리 들어온 거 있어요?" | 판매 등록 카드 구매 확률 ↑ |

- 말투: 같은 대사를 성별 · 나이로 어미만 바꿈(예: 젊은 남 "~하네요" / 젊은 여 "~해요!" / 어르신 "~구먼, ~하네"). 대사 파일에 `moment|persona|gender|text` 형식 추가, 맞는 게 없으면 지금 대사로.
- 할 일: 손님 목록(`CustomerRoster`)에 **나이대 칸** 추가 → 115개 모델을 사용자가 보고 태그(또는 머리색 · 옷 이름으로 1차 자동 분류 후 수정). 이 태깅이 가장 큰 작업.

### E1. 방 진열장 (모으는 손맛)
- 바인더 카드 칸에 **[진열]** 버튼 → 방 책장(지금 피규어가 있는 책장)의 진열 칸에 카드가 **스탠드에 세워진 실물**로 놓임. 손으로 꺼내 볼 수 있음.

### E2. 방 업그레이드 — "내 자산" 추천안 (11-19 2차 요청)

**핵심 생각**: 돈을 쓰면 사라지는 게 아니라 **자산이 방에 쌓이는 것**으로 보이게 합니다. 카드팩 = 운에 거는 돈, 업그레이드 = 확실히 남는 돈 → 7일 동안 "깡 vs 투자" 고민(5-6 · 7-2 · 7-6 해결 방향).

## 그 밖에 보완 제안 (피드백에 없던 것)
1. **소리(8-9 "생동감 없음")**: 이번 FIX와 별개로 가장 큰 빈자리. 최소 6개(카드 넘김 · 팩 찢기 · 바코드 · 결제 · 쓰레기통 · 튜토리얼 "띵")만 먼저 넣어도 체감이 큼. [사운드 에셋 후보](사운드_에셋_후보.md) 참고.
2. **Release 빌드 확인(8-12)**: 마감 청소 안내가 디버그 판에만 있던 것처럼, 디버그 판에만 의존하는 정보가 더 있는지 B5 작업 때 같이 정리.
3. **접힌 팩 단서(4-4)**: 기획 핵심인데 아직 다른 사람 테스트 전. A~C가 끝난 빌드로 처음 하는 사람 테스트를 꼭 한 번.
4. **왼손잡이(10장)**: 아직 확인 못 함 — 당기기(D1) 버튼을 정할 때 오른손/왼손을 바꿀 수 있게 만들어 두면 나중에 편함.
