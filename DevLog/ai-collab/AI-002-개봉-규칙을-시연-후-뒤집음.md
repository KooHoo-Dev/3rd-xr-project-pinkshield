# AI-002 · 개봉 규칙을 시연 후 사용자가 뒤집음

| 항목 | 값 |
|---|---|
| 날짜 | 2026-11-17 |
| 결과 | 사용자가 수정 |
| 관련 | DEC-004 |

## 상황
Claude가 설계·검토 단계에서 제안한 규칙(유니크 이상 스킵 제외, 갓팩 전용 동시 공개)을 사용자가 채택해 구현했고, Quest 시연 후 사용자가 둘 다 바꾸기로 함.

## AI가 한 제안
- 유니크·레전더리는 놓치지 않게 스킵 불가, 갓팩은 전용 연출.
- (이번 피드백에서) 레전더리 카메라 셰이크 요청에 대해 멀미 우려로 카드·더미 흔들림과 진동을 대안으로 제안 → 사용자 수용.

## 사용자가 고친 것
시연으로 직접 체험한 뒤 "전 등급 스킵 가능, 갓팩도 일반과 동일"로 변경. 설계서 단계에서는 보이지 않던 부분을 실기기 플레이로 발견.

## 배운 것
스킵/연출 규칙처럼 체감이 중요한 결정은 설계 검토만으로 확정하기 어렵고 실기기 시연 후 재검토가 필요했음. (사용자의 구체적 판단 근거는 확인 후 보강)

## 추가: 요청을 잘못 해석한 사례 (같은 날)
사용자 원문은 "카드 개봉 후 색깔 예시 카드가 먼저 나온다"였고 Claude는 이를 "카드 앞면 등급이 미리 보인다"로 해석해 카드 뒷면 쌓기 + 뒤집기를 구현. 실제로는 팩을 뜯을 때 나오는 색 판(빛줄기)을 없애 달라는 뜻이었고, 뒤집기는 눈이 아프다는 피드백으로 되돌림. 교훈: 모호한 연출 피드백은 구현 전에 "어느 장면의 무엇인지" 사진·확인을 요청.
