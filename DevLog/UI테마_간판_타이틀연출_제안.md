## 1. 지금 상태

| 화면 | 바탕 | 글자 | 버튼 |
|---|---|---|---|
| 판매 패널 · 바인더 · 정산 · 타이틀 · 최종 판 (`WorldUi`) | 베이지 (0.93, 0.91, 0.86) | 진보라 | 진보라 → 주황(가리킴) → 갈색(누름) |

같은 정보 UI가 "베이지 판"과 "검은 띠" 두 종류로 나뉘어 있고, 글꼴 크기 · 여백 · 모서리가 판마다 다릅니다.

## 2. 테마 안 (하나 고르기)

| | ⭐ A. 카드샵 굿즈 | B. 레트로 문구점 | C. 네온 밤 거리 |
|---|---|---|---|
| 느낌 | 트레이딩 카드 슬리브 · 바인더처럼, 진보라 바탕 + 분홍 · 금색 포인트 | 크림색 종이 + 굵은 손글씨 테두리, 스티커 느낌 | 어두운 남색 + 형광 분홍 · 하늘색 |
| 지금과 차이 | 버튼 색은 그대로 쓰고 판 바탕만 진보라로 → 변경 적음 | 지금 베이지 판을 살리고 검은 띠를 크림 판으로 | 전체 다시 |
| 장점 | 카드 등급 색(금 · 무지개)이 잘 보임, 카드 게임 정체성 | 따뜻하고 귀여운 슬라임 컨셉과 맞음 | 퇴근 후 밤 분위기와 맞음 |
| 단점 | 밝은 낮 가게에서 판이 무거워 보일 수 있음 | 등급 색 대비가 약함 | 낮 영업과 안 맞음, 작업 큼 |

**공통으로 할 일 (어느 안이든)**: 색 · 글자 크기 · 여백 · 모서리를 한 곳(`UiTheme` ScriptableObject)에 모으고 `WorldUi` 빌더와 TMP 3D 판이 같은 값을 쓰게 함 → 이후 색만 바꿔도 전체가 바뀜. 둥근 모서리 판은 9-slice 스프라이트 하나로.

## 3. 가게 앞 간판

| | ⭐ A. 정면 큰 간판 | B. 돌출 간판 |
|---|---|---|
| 방법 | 출입문 위 앞벽에 가로로 긴 판 + 가게 이름 글자 (TMP 3D, 밤에 은은히 빛남) | 문 옆 벽에서 인도 쪽으로 튀어나온 세로 간판 |
| 에셋 | PolygonCity `SM_Prop_LargeSign_*` 틀을 빌리거나 큐브 판 + 글자 | PolygonCity `SM_Prop_Billboard_Sign_*` |
| 장점 | 타이틀 자리(가게 앞 인도)에서 정면으로 크게 보임 → 타이틀 화면 겸용 | 거리 쪽에서도 보임 |

**가게 이름이 필요합니다.** 예: "카드깡" · "슬라임 카드샵" · "팩 터지는 집" (직접 정해 주세요).
지금 있는 `ShopSign`은 영업 중 / 마감을 색으로 보여 주는 작은 팻말이라 그대로 두고, 큰 간판을 새로 만듭니다.

## 4. 메인 메뉴 첫 등장 연출

지금: 앱을 켜면 가게 앞 인도에 서서 바로 타이틀 판이 보임.

| | ⭐ A. 간판 점등 (작음) | B. 카메라 비행 (중간) | C. 비행 영상 (큼, HANDOFF P4) |
|---|---|---|---|
| 방법 | 화면이 어두운 거리에서 밝아지며 → 간판 글자가 하나씩 켜지고(네온 점등) → 타이틀 판이 아래에서 떠오름, 2~3초 | 플레이어를 높은 곳에 두고 가게 앞으로 천천히 내려오는 이동 (VR 멀미 위험 → 페이드로 짧게) | Cinemachine으로 거리를 녹화한 영상을 곡면 스크린에 → 디졸브 |
| 멀미 | 없음 (플레이어는 안 움직임) | 있음 | 없음 |
| 작업 | 간판(3장)과 함께 하루 | 하루 | 2~3일 |

**추천 순서**: 간판 A → 첫 등장 A(간판 점등) → 테마 A 공통 작업(`UiTheme`) → 남는 시간에 각 판 다시 칠하기.
