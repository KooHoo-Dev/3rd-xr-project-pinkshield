## P1. 젤리 버튼 (상자 열기 · 퇴근 · 결제)
| # | 볼 것 | 결과 |
|---|---|---|
| 1-1 | 세 버튼이 진보라 받침 + 금 테 + 돔 캡으로 보임 (원래 큐브는 안 보임) | |
| 1-2 | 글자가 받침 앞 명판 위에 있고, 서 있는 자리에서 읽힘 (반대로 보이면 알려 주세요) | |
| 1-3 | 손가락으로 누르면 캡이 납작해지고, 떼면 통 튀어 오름 · 실행도 전처럼 됨 (퇴근은 꾹 0.5초) | |
| 1-4 | 레이 · 손가락을 대면 캡이 밝아지고 금 테가 버튼 색으로 | |
| 1-5 | 버튼 외곽선 · 둘레 빛 판이 어색하지 않음 (빛 판은 버튼 색, 흰색 아님) | |
| 1-6 | 집의 **불 끄고 자기 스위치는 그대로** | |
| 1-7 | 튜토리얼 강조(외곽선)가 버튼에 여전히 잘 보임 | |

## P2. 등급별 개봉 연출 (디버그: "레전더리 확정 팩" · "유니크 히트")

|---|---|---|
| 2-1 | 노말: 연출 없음 / 레어: 하늘색 후광 + 방울 8개 + 통 튐 (가볍게) | |
| 2-2 | 수퍼레어: 연보라, 방울 2겹 · 별 · 회전 빛줄기 · 테 빛 · 링 1겹 | |
| 2-3 | 유니크: 금색, 주변 살짝 어둡게 · 색종이 · 링 2겹 · 짧은 부르르 · 진동 2번 | |
| 2-4 | 레전더리: 무지개, 둥실 떠오름 · 빛줄기 2겹 반대 방향 · 링 3겹 · 색종이 많이 · 부르르 | |
| 2-5 | 빛이 카드 앞면(그림 · 글자)을 가리지 않음, 눈부시지 않음 | |
| 2-6 | 빨리 넘기면 앞 카드 연출이 바로 꺼짐 (빈 자리에 빛이 남지 않음) | |
| 2-7 | 상자 10팩: 하이라이트 카드도 같은 연출, 팩 뜯을 때 폭죽이 돔 방울 모양 | |
