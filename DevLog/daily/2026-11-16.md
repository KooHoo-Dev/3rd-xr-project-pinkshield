## 한 일
- **카드 아트 방향**: VR에서 2D 카드가 어색한 원인을 "평면 그림"이 아니라 "빛·두께·깊이에 반응하지 않는 판자 같은 카드"로 정리. 아트는 3D 렌더풍 캐릭터 + 2D 배경으로 만들고, 입체감은 셰이더에서 내기로 함 → `Assets/98. Doc/카드아트_Gemini_프롬프트_가이드.md`
- **첫 카드(앵커)**: F-N1 불씨 슬라임을 50장 스타일 기준으로 삼아 Gemini에 전달
- **시스템 설계서 v1**: 유지보수 중심 — 수치는 ScriptableObject, 규칙(순수 C#)과 VR 뷰 분리, 카드 50장은 CSV 원본, 확률표를 테스트 기대값으로 → `Assets/98. Doc/카드깡_시스템설계서_v1.md` (검토 완료, DEC-001)
- **폴더 정리**: 설계서 구조로 이동 — `01. Scripts/Runtime·Editor·Tests`, `02. Data`, `04. Art`, `05. Shaders` (`.meta` 함께 이동해 참조 유지)
- **패키지 정리**: Netcode · Multiplayer · Visual Scripting · Collab 제거. AR Foundation은 Meta OpenXR 의존성이라 유지, AndroidXR은 패키지 매니저로 제거 예정(기능은 끔)
- **데이터 계층**: asmdef 3종, enum 값 명시, 설정 SO 5종(등급·팩 확률·경제·진행·점수, 기본값 = 기획서 수치), `cards.csv` 50장 → CSV 임포터·데이터 검증기 (`Tools > CardShop`)
- **흐름 뼈대**: GameContext · GameSession · GameFlow + 페이즈 7개, EconomyRules. 일시정지는 `Time.timeScale` 대신 플래그 (XRI 조작 유지)
- **테스트**: EditMode 18개 — 기획서 단서 확률표·가격표를 기대값으로, 씬 참조 누락 검사
- **Shop 씬**: 빌더 메뉴로 생성 (XR Origin, GameContext 설정 자동 연결, 디버그 페이즈 패널). 씬은 Title/Shop 2개 대신 1개로 변경 (설계서 반영)
- **Quest 빌드**: `Tools > CardShop > Quest` 설정 적용·빌드 메뉴. AR 기능 8개·AndroidXR 기능 끔, 앱 이름·패키지 ID 변경. Quest 3S에서 7일 루프 끝까지 진행, 72fps, 헤드셋 녹화 확인
- **DevLog 구축**: 일일 노트·버그 카드·결정·AI 협업 양식, Unity F9 버그 캡처 도구(`Assets/01. Scripts/Editor/DevLog/`), 클립보드 스크린샷 스크립트, `/devlog` 스킬

### 저녁: 팩 개봉 구현 (2일차 범위)
- **팩 확률 판정** `PackRoller`: 갓팩 → 레전더리 확정 → 슬롯 판정 순서, 단서 보정, 1회성 강제(치트). 기획서 ③④ 확률표를 대량 시행 테스트로 고정 (커밋 `2beb829`)
- **선반**: 단서 배치 75/20/5, 매일 재배치, 놓을 때 앞/뒤를 판정해 방향 유지 스냅(DEC-001), 선반 밖에 놓친 팩은 3초 뒤 복귀
- **개봉 규칙** `PackOpeningService`: 개봉 시작 시 차감, 하루 첫 팩 무료, 상자 10팩, 개봉 즉시 보유·도감 반영
- **상자 결과판**: 1/10~10/10 팩별 결과와 합계를 한 줄씩 표시, 연출 중 개봉 잠금. **개봉 실패 안내**: `WorldToast` 말풍선 + 거부 진동 (커밋 `806c6eb`)
- **개봉 연출 설계**: Pocket의 "고르기 → 자르기 → 한 장씩 넘기기 → 모아 보기"를 VR로 옮기는 설계와 보완 검토 8건 → `Assets/98. Doc/카드팩_개봉연출_설계.md`
- **자르기 개봉** `TearGestureOpen`: 왼손 그립으로 잡으면 팩이 눈앞 35cm에 월드 고정 → 오른손 트리거를 누른 채 윗부분 선을 따라 그어 70%면 개봉. 손끝 또는 레이저로 자를 수 있음 (BUG-002). 오른손 인터랙터 찾기는 `HandFinder`로 분리
- **한 장씩 넘기기** `CardRevealer.PackSequence`: 팩이 있던 자리에 카드 5장이 앞면 묶음으로 나오고, 오른손 트리거마다 맨 앞 카드가 카운터로 날아감. 등급별 멈춤·진동 1차 적용
- **눈높이 보정** `PlayerHeightCalibrator`: XR Origin을 바닥 기준 트래킹으로 두고, 시작·새 게임 때 눈높이를 1.6m에 맞춤. 디버그 패널에 수동 버튼 추가
- **씬**: 팩 테이블 위치를 카운터와 겹치지 않게 옮김(`PackTablePos`), 씬 다시 생성
- **카드 아트 프롬프트 재설계**: 수퍼레어 정의 변경, 슬라임 몸 모양·얼굴 기본틀 고정, 유니크 왕관 → 속성별 머리 장식 (DEC-002)
- **버그 3건 해결**: BUG-001 프리팹 스크립트 참조 누락 · BUG-002 오른손으로 안 잘림 · BUG-003 카드 묶음이 Rigidbody 보간 때문에 옛 자리로 되돌아감

## 막힌 점 · 버그
- Quest가 adb에서 계속 `unauthorized` → 처음 허용한 창이 "파일 액세스" 창이었던 것으로 추정. 헤드셋 개발자 설정에서 USB 디버깅 권한 취소 → 재연결 → RSA 키 지문이 있는 "USB 디버깅 허용" 창에서 허용하니 해결
- [BUG-001](../bugs/BUG-001-팩-트리거-개봉-안됨-스크립트-참조-누락.md) 팩을 든 채 트리거를 당겨도 안 열림 → 한 파일에 MonoBehaviour 2개라 프리팹에 Missing Script
- [BUG-002](../bugs/BUG-002-오른손-트리거로-팩이-안-잘림.md) 오른손 트리거로 안 잘림 → 판정점이 컨트롤러 원점이었음 + 시뮬레이터의 Shift 손 전환 구조
- [BUG-003](../bugs/BUG-003-개봉한-카드-묶음이-눈앞에-안-보임-Rigidbody-보간.md) 카드 묶음이 가끔 카운터로 튐 → Rigidbody 보간이 Transform을 옛 물리 위치로 덮어씀
- 시뮬레이터에서 "왼손 그립 유지 + 오른손 트리거"는 키를 누르는 방식으로 안 됨 → 빠른 동작 토글(`` ` ``, Space)로 테스트
