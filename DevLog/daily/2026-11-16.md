## 한 일
- **카드 아트 방향**: VR에서 2D 카드가 어색한 원인을 "평면 그림"이 아니라 "빛·두께·깊이에 반응하지 않는 판자 같은 카드"로 정리. 아트는 3D 렌더풍 캐릭터 + 2D 배경으로 만들고, 입체감은 셰이더에서 내기로 함 → `Assets/98. Doc/카드아트_Gemini_프롬프트_가이드.md`
- **첫 카드(앵커)**: F-N1 불씨 슬라임을 50장 스타일 기준으로 삼아 Gemini에 전달
- **시스템 설계서 v1**: 유지보수 중심 — 수치는 ScriptableObject, 규칙(순수 C#)과 VR 뷰 분리, 카드 50장은 CSV 원본, 확률표를 테스트 기대값으로 → `Assets/98. Doc/카드깡_시스템설계서_v1.md` (검토 완료, DEC-001)
- **폴더 정리**: 설계서 구조로 이동 — `01. Scripts/Runtime·Editor·Tests`, `02. Data`, `04. Art`, `05. Shaders` (`.meta` 함께 이동해 참조 유지)
- **패키지 정리**: Netcode · Multiplayer · Visual Scripting · Collab 제거. AR Foundation은 Meta OpenXR 의존성이라 유지, AndroidXR은 패키지 매니저로 제거 예정(기능은 끔)
- **데이터 계층**: asmdef 3종, enum 값 명시, 설정 SO 5종(등급·팩 확률·경제·진행·점수, 기본값 = 기획서 수치), `cards.csv` 50장 → CSV 임포터·데이터 검증기 (`Tools > CardShop`)
- **흐름 뼈대**: GameContext · GameSession · GameFlow + 페이즈 7개, EconomyRules. 일시정지는 `Time.timeScale` 대신 플래그 (XRI 조작 유지)
- **테스트**: EditMode 18개 — 기획서 단서 확률표·가격표를 기대값으로, 씬 참조 누락 검사
- **Shop 씬**: 빌더 메뉴로 생성 (XR Origin, GameContext 설정 자동 연결, 디버그 페이즈 패널). 씬은 Title/Shop 2개 대신 1개로 변경 (설계서 반영)
- **Quest 빌드**: `Tools > CardShop > Quest` 설정 적용·빌드 메뉴. AR 기능 8개·AndroidXR 기능 끔, 앱 이름·패키지 ID 변경. Quest 3S에서 7일 루프 끝까지 진행, 72fps, 헤드셋 녹화 확인
